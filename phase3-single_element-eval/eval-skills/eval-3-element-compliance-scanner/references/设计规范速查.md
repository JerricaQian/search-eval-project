## 二、组件源样式字典（标签/角标底图的 CSS 级精确值）

> 判定"标签底色/描边/阴影是否合规"时，比对以下源值。渐变按 `linear-gradient(角度deg, #hex 位%, ...)` 精确匹配语义色系（角度/停止位小幅差异见 P10，但**色相必须落在对应语义**）。

**常规标签渐变族（圆角 6px=3pt）——按语义收敛的 5 套标准色：**

- 绿（推荐/优选/榜单）：`linear-gradient(135deg, #38D12A 0%, #00B300 100%)`
- 黄（权益/福利/会员）：`linear-gradient(135deg, #FFE74D 0%, #FFDD00 100%)`
- 橙（热销/促销/销量榜）：`linear-gradient(135deg, #FF9233 0%, #FF5500 100%)`
- 蓝（资质/官方/服务保障）：`linear-gradient(135deg, #33A0FF 0%, #0A77F5 100%)`
- 青蓝双层（蓝色系强调）：外层 `linear(315deg,#0FA7FF 5%,#22C4FE 100%)` / 底 `linear(135deg,#3392FF 0%,#2053E2 100%)`

**其它专用标签底图：**

- 限时优惠标（标签区/价格区）：`linear-gradient(135deg, #FF6619 0%, #FF2D19 100%)`
- 到手价标（价格说明专用）：允许红/橙红实心底 + 白字，可为纯色 `#FF4B3E` 或同一价格红色系渐变；仅限“到手价”价格说明语义，不外推到其他价格区标签。
- 直播中标（头图区）：`linear-gradient(129deg, #ff4791 -11%, #ff3375 104%)`（组件源 138deg #FF4791→#FF3375；无描边）
- 会员标·黑金：`linear-gradient(45deg, #101010 0%, #323232 100%)` + 描边 `#B3B3B3 1px` + 圆角 6px
- 会员标·浅金：`linear-gradient(119deg, #FFE4C5 0%, #F7CEA4 100%)`（圆角 6px）
- 会员标·紫：`linear-gradient(315deg, #6D59FE 0%, #8C00EE 100%)` + 描边 #979797 1px
- 会员标·亮黄：`linear-gradient(135deg, #FFEB32 0%, #FFE400 100%)` + 描边 #979797 2px
- 新店信誉圆标底：`linear-gradient(139deg, #63E063 0%, #2DD02D 100%)` + 描边 `#00A72D 0.76px`

**描边字典：** 新店绿 #00A72D 0.76px；闪电新品黑 #000000 0.82px / 白 #FFFFFF 0.49px；浅灰分隔 #979797 0.5~1px；卡片外层白 #FFFFFF 2~3px；选中态蓝 #2A91FF 3px / #268BFF 1px。

**阴影字典：** 广告标 `DROP_SHADOW r4 (0,0) #000000@0.50`；大象 Logo `DROP_SHADOW r2 (0,2) #000000@0.04`；蓝底高光 `INNER_SHADOW r1.1 (0.5,0.5) #FFFFFF@0.80`；券标/常规标背景 `BACKGROUND_BLUR r0/r6`。

## 三、分区规范清单（9 画板 × 分区：每个元素落在哪个分区，就套该分区的规则）

判定单一元素时，**先定位它属于哪张卡的哪个分区**，再看该分区「允许元素 / 最大条数 / 优先级 / 可用样式 / 可用色值」。

### 1. 商品卡片
- **头图区(氛围图/腰封)**：允许 商家头图/统一腰封/SA 级营销标签(仅走腰封，腰封 1 条)；腰封文字 16px(8pt)Medium 白字 #FFFFFF；无描边无阴影。营销标签不单独浮层。
- **头图-钻石属性/IP 角标**：钻石属性标签(时令/鲜活/冰镇/冷藏等)或特殊 IP，1 项，IP>属性；标签圆角 6pt，白字 20px(10pt)Medium，渐变底(绿#38D12A→#00B300 / 蓝#0FA7FF→#22C4FE / 黄 / 橙)，无描边无阴影。**「时令」绿标属此区，合规。**
- **标题区**：履约标签(前置，黄底 6pt 圆角)+标题 30px(15pt)Medium #111111；标题≤2 行；外卖/团购/酒店前置商家名。
- **基础信息区**：评价/销量/距离/规格，各≤1 项；正文 24px(12pt)Regular，无底色；次要 #555555 / 弱化 #888888。
- **标签区**：文字样式标签（三级分层，**去底色**）24px(12pt)；三级=保障/属性/服务/统计(仅灰 #888888)；二级=高优决策(彩色高亮)；一级=强 IP(特殊色)。
- **价格区(收敛区)★**：主价格、单价、会员价、平台保障和其他说明整体收敛为文字样式，价格&说明红 #F52916/#FF2D19，会员价棕 #764618，平台保障黑 #111111，其余灰 #888888。**仅允许 红/棕/黑/灰。唯一容器例外是“到手价”价格说明标：允许红/橙红实心底 + 白字，属合规价格标，不判“价格区标签化”。**
- **推荐理由/下挂区**：推荐理由/增值服务/属性说明，仅灰色字 24px(12pt) #555555/#888888；文字≤1 行。

### 2. 商家卡片-文字下挂
- **头图区**：直播标/SA 营销标(≤1 项)+营业状态(≤1 项)；营业状态白字 18px(9pt)Medium+深色半透明底(24h营业/10:00营业/暂停营业/尚未营业/即将营业)；直播标/资质认证 24px(12pt)Medium #111111；无阴影。
- **标题区**：履约标签+标题 30px(15pt)Medium #111111；标题≤1 行(比商品卡少一行)。**履约标底色按履约方式区分且均合规：到店=橙底、外卖=黄底、上门=黄底、团购/配送等按业务对应底色；同页出现橙底「到店」与黄底「外卖/上门」并存属规范允许，不判违规。同页多张卡的同类标签因语义分流而配色不同（如卡1到店橙底、卡3外卖黄底）属规范内区分手段，不判"跨卡不统一"。**
- **服务/履约文字标签区**：卡片下半部一排纯文本服务标（门店上新/刚刚有用户看过/"XX评价语"/支持自取/可开发票/放心吃等），**浅灰底灰字纯文本样式**，各标规格统一即合规。**折扣标（如「7.76折起」）允许「白底 + 橙描边 + 橙字」样式，属许可样式，不判违规。标签"条数多少"属复杂度计数口径（static-element-complexity-scanner），不属本"规范符合性"维度。**
- **评分/新店区 ★**：评分/优选新店/新店入驻，各≤1 项；区标题 32px(16pt)Medium #111111；新店类 24px(12pt)Regular，**无底色裸文字**；**优选新店/新店入驻=绿字 #00A72D(裸文字，无底色)**。**「优选新店」真实归属此区（不是商品卡价格区）；绿裸字为该区既定样式，与标签区文字标签口径不同（见 P1）。**
- **距离/服务时间区**：评价/距离/到家履约/上门时间，各≤1 项；正文 24px(12pt)，无底色；距离 #111111 居右。
- **标签区(三级分层)**：文字标签 24px(12pt)；三级灰 #888888(Regular)；二级彩色(榜单橙 #FF5500 / 公立青 #029781 Light / 评级蓝 #0A77F5)；一级强 IP(发型师洋红 #A31F73)。
- **下挂区**：商品下挂(价格+名)/服务下挂(标题+副标题)，文本≤1 行 24px(12pt)；灰 #555555；推荐理由棕 #764618(Light)。

### 3. 商家卡片-图文下挂
- **头图区**：比文字下挂多「商家资质认证」与「特殊腰封」；直播/营销/资质各≤1 项+营业状态≤1 项；营业状态 18px(9pt)白字+深色底；直播标/资质认证/特殊腰封 24px(12pt)Medium #111111；中头图 圆角 12pt。
- **标题区**：履约标签+标题+配送时长(居右)；标题 30px(15pt)Medium #111111；标题≤1 行。
- **评分/新店区**：同文字下挂（优选新店/新店入驻 绿裸字 #00A72D，待与标签区统一）。
- **基础信息区**：月售/距离，各≤1 项；配送距离 32px(16pt)Medium，正文 24px(12pt)；距离 #111111 居右。
- **标签区(三级分层)**：文字标签 24px(12pt)；会员价/直播特惠 22px(11pt)Light；三级灰 #888888；二级彩色 #FF5500；会员价棕 #764618；直播特惠红 #FF2D19；榜单占位 #C2C2C2；钻石属性 #111111(Medium)。
- **图文下挂区**：带图商品/团购项，仅左下角坑位；下挂图片圆角，图文并排 24px(12pt)；商品名 #111111，说明 #555555。**折扣标（如「0.8折」「2.5折」）允许「浅红底 + 红字」标签样式，属下挂区许可样式，不强制去底色，不判违规；价格 #FF2D19/#F52916 红字。**

### 4. 酒店卡片(商家商品卡)
- **头图区**：直播标/SA 营销标/视频标各≤1 项+营业状态；认证角标渐变 6pt 圆角(住吧黑 #101010→#323232 等)；营业状态 18px(9pt)白字。酒店独有资质认证链，支持视频标。
- **标题区**：履约标签(前置)+标题+酒店等级(后置)；标题 30px(15pt)Medium #111111；标题≤2 行。酒店等级后置为酒店独有。
- **基础信息区**：直线/路面距离/房型面积/预订热度，各≤1 项；正文 24px(12pt)，热度 22px(11pt)；距离 #111111，房源低价 #FF5500。
- **标签区(三级分层)**：文字标签 24px(12pt)；三级灰 #888888；二级彩色(豪华好评榜 #FF5500)；会员棕 #7A3100；积分抵扣多色 #8F5300/#2C5AB8/#964600/#751736/#633A00/#001A9E(P4 建议收敛)。
- **双行/下挂区**：酒店信息+电竞设备(双行)≤2 行；24px(12pt)灰 #555555，无底色。电竞/长租房独有。

### 5. 度假/酒店套餐卡片
- **头图区**：出发城市标等(氛围图)≤1 项；头图 12pt 圆角；出发城市白字 20px(10pt) #FFFFFF。
- **标题区**：履约标签+标题+旅游天数；标题 30px(15pt)Medium #111111；标题≤2 行；旅游类标题展示天数。
- **标签区(仅灰)★**：住/景/享/吃/行/团服务保障等文字标签，**仅支持灰色文字** 24px(12pt) #888888/#555555；**比商家卡更严：不允许彩色高亮。**
- **旅游要素区**：机票跟团/拼小团大巴/司机驾龄车龄/酒店档次/车型 24px(12pt)；类目 #111111，说明 #555555。
- **价格区**：套餐价格(居右固定，大号红 #FF2D19)+评分/销量(居左，24px(12pt)灰 #555555)。

### 6. 主点卡片
- **头图/标题区**：地点/机构名称(地铁站/商场/医院/学校/景区)；标题 30px(15pt)Medium #111111；标题≤2 行；无履约标签。
- **基础信息区**：地点属性(区域/地铁线/地址/门诊时间)+新店，各≤1 项；正文 24px(12pt)Regular；次要 #555555，关键 #111111；**新店绿字 #00B300(与商家卡 #00A72D 略异，P2 建议统一)。**
- **榜单/擅长区**：全国排名榜单/医生擅长 24px(12pt)弱灰 #777777；医院场景独有「擅长:…」。
- **免责声明区 ★**：信息来源合规声明 1 行；20px(10pt)最弱灰 #C2C2C2；主点卡独有（如"以上医院信息基于互联网公开信息收集整理"）。
- **推荐理由/下挂区**：推荐理由棕字 24px(12pt)Light #764618；聚合子项(团购/入住商家/园区好店)。

### 7. 演出/电影卡片
- **头图区**：固定尺寸头图，**★不放标签(0 标签)**；头图圆角 12pt。
- **基础信息区**：演出日期/场馆/场次时间，各≤1 项；正文 24px(12pt)，时间 22px(11pt)；次要 #555555，时间 #111111。
- **价格区**：区间价格/最低价；**价格居左固定(与商品/套餐卡居右相反)**；大号红 40px(20pt)Medium #FF2D19。

### 8. 容器404326(弱下挂容器)
- **复用模版**：通用商品卡片模版/弱下挂；复用原子样式，无独立分区规则；复用统一色板。

### 9. 容器433557(医美/连锁容器)
- **基础信息区**：机构资质/规模(18城23店等)，各≤1 项；24px(12pt)；资质 #111111，规模棕 #764618。
- **推荐理由/下挂区**：推荐理由棕字 24px(12pt)Light #764618；团购项([爆款推荐]/[人气推荐]) #111111。

## 四、已知规范弱点（判定时的"灰区"，遇到需标注为规范本身问题而非元素违规）

| 编号 | 弱点 | 判定影响 |
|------|------|---------|
| P1 | 「评分/新店区」绿裸字 与 标签区「文字标签」口径不统一 | 新店绿裸字属既定样式，判合规但注明"规范内部待统一" |
| P2 | 新店绿值跨卡不一致(商家卡 #00A72D / 主点卡 #00B300) | 两值都属合规，勿因色差判违规 |
| P3 | 「彩色高亮」缺封闭色值白名单 | 二/一级彩色标签用色靠语义判定，越界色需人工确认 |
| P4 | 同语义多个近似色值(价格红 2 个、棕 2 个、弱灰 4 个、积分抵扣 6 色) | 近似值都属合规，但可提示收敛建议 |
| P5 | 非阶梯字号(14.5px/13.9px) | 落在标准阶梯外的字号判可疑/不达标 |
| P6 | 规则散落画布标注，缺结构化 | 已抽成本清单 |
| P7 | 价格位置各卡不统一 | 按卡类型的既定位置判定，勿跨卡套用 |
| P8 | 头图可放内容各卡差异大、无统一枚举 | 严格按当前卡型头图允许项判定 |
| P9 | 规范曾以渲染实例值记录，缺组件源定义 | 已补「组件源样式字典」，以其 CSS 值为准 |
| P10 | 同语义标签渐变角度/色值不统一(绿标 135°/139°/144°) | 角度小幅差异属合规，色相错位才判违规 |
