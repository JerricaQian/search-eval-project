## 三档解释与证据展示契约 / 统一输入与执行契约

通用条款见 [[单一元素评测通用契约]]（`phase3-single_element-eval/单一元素评测通用契约.md`），本 Skill 仅列专属部分：

- `observableFact` 书写要求：完整保留 `finding` 四字段用于校验；问题卡只展示"可见事实，评级为<评级>。用户影响。"，不重复展示质量规则和判定过程。`observableFact` 必须写清元素原文、位置和可见缺陷。
- 示例输出：`C1 标题"限时特惠"末尾被截断，无法完整读出优惠条件，评级为不达标。用户无法判断该优惠是否适用于当前商品。`
- **Phase2 事实优先：**图片/文字元素、渲染状态、文本完整性、自然截断和图片归属必须读取 `render`、`textFacts` 与 `factInventory`；Phase3 只判断质量、相关性与合规，`uncertain` 不得作为不达标或优秀依据。

## 工具定位

本 Skill 用于评测搜索结果页或信息页截图中每个**独立元素**的供给呈现质量，即页面内的图片和文字是否属于低质量供给。AI 逐元素检查图片的合规性、完整性、画质、比例、相关性，以及文字的完整性、准确性、用户视角表达、相关性，对每个元素独立判定是否达标。最终按**搜索词 × 元素**颗粒度输出评测结论。

**与同系列 Skill 的边界：**

- 本 Skill 关注"每个独立元素本身是否为低质量供给"（单一元素维度 — 元素自身质量问题）。
- `supply-completeness-scanner` 关注"组件内应有的元素是否缺失"（单一组件维度 — 元素是否存在的问题）。
- 两者互不重叠：`supply-completeness-scanner` 判断"该有的元素有没有出现"，本 Skill 判断"已出现的元素质量是否合格"。同一页面可被两个 Skill 分别评测，互不影响。

**评估对象定义：** 页面上可独立识别的最小信息单元。包括但不限于：商卡头图、团购商品图、图筛配图、UGC 内容配图、店铺标题、团购标题、商品标题、图筛文字、标签文字、价格文字等。每个元素独立判定。

## 核心概念

### 图片质量检查维度

对页面中每一张可见图片（含商卡头图、团购横滑商品图、图筛配图、UGC 卡片配图等），依次检查以下五个维度，任一维度不达标即判定该图片元素为低质量供给：

**1）合规性（底线要求）**
图片不得出现任何违规内容，包括政治敏感、色情、暴力、血腥、裸露。低俗擦边内容（如低俗卡通形象、暗示性图案）也应标注为合规性存疑。若出现则为 🔴 不达标。

**2）完整性**
图片主体内容必须完整展示，不得出现以下情况：关键部分被裁剪导致主体不完整、图片未加载（显示占位图/空白区域/加载失败图标）、主体内容被遮挡或缺失。若出现则为 🔴 不达标。

**3）画质**
图片不得出现以下情况：带有无关水印、出现无关 Logo（非商家自身品牌 Logo）、明显拼接痕迹、版权标记、严重模糊导致内容无法辨识。若出现则为 🔴 不达标。

注意：商家自制宣传图中包含的**自身品牌 Logo 和营销文案**属于商家正常运营行为，不算"无关 Logo/水印"，不扣分。判断标准是 Logo/水印是否与该商家/商品相关——相关的是品牌元素，不相关的才是"无关水印"。

**4）比例**
图片必须保证视觉统一性，不得出现明显拉伸或变形（如人物/物体比例失调、圆形物体呈椭圆形等）。若出现则为 🔴 不达标。

**5）相关性**
图片必须与搜索词或所属模块含义相关。不得出现以下情况：图片内容与搜索词完全不相关（如搜索"鸭脖"结果中出现人脸表情包）、团购商品图与团购标题不符（如标题写"涮肉套餐"但图片是储值活动海报、标题写"羊肉菜品"但图片是活体小羊照片）。若出现则为 🔴 不达标。

**相关性判断的关键原则：** 图片应展示用户期望看到的内容。对于商品/套餐类，用户期望看到商品实物或服务场景；对于店铺头图，用户期望看到与店铺业态相关的内容。如果图片展示的内容让用户无法将其与标题/搜索词建立合理关联，即判定为不相关。

### 文字质量检查维度

对页面中每一段可见文字（含店铺标题、团购标题、商品标题、图筛文字、标签文字等），依次检查以下四个维度，任一维度不达标即判定该文字元素为低质量供给：

**1）完整性**
标题必须展示完整核心信息，用户能够获取关键决策信息。以下情况判定为不达标：

- 标题被标签/角标等 UI 元素严重挤占，导致核心店名或服务信息截断缺失，用户无法获取关键决策信息。
- 标题严重缺字、漏字，影响用户理解。

以下情况**不判定为不达标**：

- 因展示空间限制导致的末尾省略（以"..."结尾），只要核心信息（店铺名/品牌名/主要服务类型）已完整展示。判断标准是"用户能否从可见部分获取关键决策信息"。
- 店名过长导致末尾英文/附加信息被截断，但核心中文品牌名和服务定位已完整呈现。
- 团购标题末尾省略，但价格/服务名称/时长等核心信息在可见范围内已完整展示。
- 横滑列表边缘元素的自然裁切（属于交互设计的正常行为）。
- 页面滚动位置导致组件仅部分露出（自然截断，非元素质量问题）。

**2）准确性**
文字不得出现任何错别字。若出现则为 🔴 不达标。

**3）用户视角表达**
主要适用于图筛文字。图筛展示的文字应当是用户的实际搜索视角表达，不应使用行业术语或非用户视角的分类方式。例如：用户搜索"网球"，图筛文字为"个人网球"，"个人网球"不是用户会使用的搜索词，有理解成本，判定为不达标。若出现则为 🔴 不达标。

**4）相关性**
文字内容必须与搜索词相关，不得出现明显与搜索词不符的文字。若出现则为 🔴 不达标。

## 评估标准

对**每个独立元素**判定：

| 评级 | 条件 | 含义 |
|------|------|------|
| 🟢 优秀 | 该元素在所有适用检查维度上均无问题 | 不属于低质量供给元素 |
| 🔴 不达标 | 该元素在任一检查维度上存在问题 | 属于低质量供给元素 |

> **评级说明：** 本指标不设"达标"中间档。每个元素只有"优秀"和"不达标"两种结果——要么是合格的供给，要么是低质量供给。这是因为供给质量是底线性质的指标：图片加载失败、文字错别字、图文不符等问题没有"轻微"和"严重"之分，出现即影响用户体验。

> **图片和文字分别判定：** 一个元素是图片就按图片五维度检查，是文字就按文字四维度检查。同一个组件内的不同元素各自独立判定，互不影响——即使商卡头图不达标，该商卡的标题仍可能是优秀。

## 执行步骤

### Step 1：接收截图并确认评测范围

1. 用户提供页面截图（单张或多张）。使用图片读取工具加载所有截图。
2. 识别搜索词（顶部搜索栏文字）；若为非搜索场景（如详情页、列表页），识别页面所属场景名称代替搜索词。
3. 识别当前 Tab/频道（全部、外卖、团购等），若页面无 Tab 概念可省略。
4. 若为多屏截图，记录屏次，最终需合并为一份完整报告。

### Step 2：识别页面中所有可见元素

从截图顶部到底部，按视觉顺序逐区域扫描，将每个可独立识别的图片和文字登记为独立元素。典型的元素来源区域包括：

**2a. 图筛区**
- 每个图筛项拆分为两个元素：图筛配图（图片元素）+ 图筛文字（文字元素）。

**2b. 筛选/排序条**
- 每个筛选项文字为一个文字元素。

**2c. 商卡区**
- 每张商卡内的元素独立登记：商卡头图（图片）、店铺标题（文字）、品类/商圈等标签文字（文字）、团购标题（文字）、价格（文字）。
- 若商卡展开了团购横滑区，每个团购商品图（图片）和团购商品标题（文字）各为独立元素。
- 若为外卖商卡，下挂菜品区的每个菜品图（图片）和菜品名称（文字）各为独立元素。

**2d. UGC 内容区**
- 每张 UGC 卡片的配图（图片）和标题（文字）各为独立元素。

**2e. 其他区域**
- 页面中出现的任何其他可见图片和文字，按同样规则登记。

为每个元素编号，记录其所属区域/组件、元素类型（图片/文字）和内容简述。

> **边界被截断的元素处理：** 因页面滚动位置导致仅部分露出的元素（如截图底部只露出半张商卡头图），不将这种自然截断视为该元素的质量问题。仅分析可见部分，若可见部分本身无质量问题，判定为优秀；若可见部分已呈现出质量问题（如可见部分已能看出图片与搜索词不相关），正常判定为不达标。

### Step 3：逐元素检查质量

对每个元素，根据其类型（图片/文字）适用对应的检查维度：

**3a. 图片元素 — 依次检查五个维度**

按以下顺序逐一检查，发现任一问题即记录并标记不达标：

1. **合规性**：是否存在违规内容（政治敏感/色情/暴力/血腥/裸露/低俗）？
2. **完整性**：主体是否完整展示？是否存在加载失败/占位图/空白？
3. **画质**：是否存在无关水印/无关 Logo/拼接痕迹/版权标记/严重模糊？（商家自身品牌 Logo 和营销文案不算）
4. **比例**：是否存在明显拉伸或变形？
5. **相关性**：图片内容是否与搜索词/标题/模块含义匹配？

**3b. 文字元素 — 依次检查四个维度**

按以下顺序逐一检查，发现任一问题即记录并标记不达标：

1. **完整性**：核心信息是否完整可读？是否存在被标签严重挤压导致关键信息截断、严重缺字漏字？（正常的末尾省略不算）
2. **准确性**：是否存在错别字？
3. **用户视角表达**（仅图筛文字适用）：是否为用户视角的自然表达？
4. **相关性**：是否与搜索词相关？

对每个发现的问题，记录：问题维度、具体问题描述。

### Step 4：汇总与统计

1. 统计所有元素的判定结果：优秀数和不达标数。
2. 分别统计图片元素和文字元素的不达标情况。
3. 按问题维度归类统计（如"图片相关性不达标 X 个""文字完整性不达标 X 个"），用于发现系统性问题。

### Step 5：输出结果

**5a. 问题元素明细表：**

仅列出判定为 🔴 不达标的元素（若全部优秀则注明"无不达标元素"）：

| Tab/场景 | 所属组件 | 元素类型 | 元素内容 | 问题维度 | 问题描述 | 评级 |
|----------|---------|---------|---------|---------|---------|:----:|
| Tab名 | 如"商卡3 滋味曹氏鸭脖" | 图片/文字 | 如"团购商品图-微辣" | 图片-相关性 | 商品图为人脸表情包，与鸭脖食品完全无关 | 🔴 |

**5b. 评测总览（按 Tab 维度）：**

| Tab/场景 | 元素总数 | 🟢优秀 | 🔴不达标 | 不达标率 |
|----------|:------:|:-----:|:-------:|:------:|
| Tab名 | N | N | N | XX% |

**5c. 问题维度分布（按不达标原因归类）：**

| 问题维度 | 不达标元素数 | 涉及元素 |
|---------|:---------:|---------|
| 图片-合规性 | N | 元素列表 |
| 图片-完整性 | N | 元素列表 |
| 图片-画质 | N | 元素列表 |
| 图片-比例 | N | 元素列表 |
| 图片-相关性 | N | 元素列表 |
| 文字-完整性 | N | 元素列表 |
| 文字-准确性 | N | 元素列表 |
| 文字-用户视角 | N | 元素列表 |
| 文字-相关性 | N | 元素列表 |

若某一问题维度出现 3 个以上不达标元素，应重点标注，这通常指向系统性问题。

**5d. 总结说明：**

在表格下方附一段文字总结，包含：整体供给质量评价（优秀/存在问题）、不达标元素的典型问题和具体表现、系统性问题分析（如"多个团购商品图存在图文不符，可能是商家上传图片审核缺失"）、建议优先处理的问题类型。

### Step 6：自检

- 每个元素是否都独立判定了？是否存在以商卡为单位笼统打分的情况？
- 图片是否依次过了合规/完整性/画质/比例/相关性五维度？文字是否过了完整性/准确性/用户视角/相关性四维度？
- "正常末尾省略"是否被误判为文字完整性不达标？（核心信息已完整展示的末尾省略不算）
- 商家自身品牌 Logo/营销文案是否被误判为"无关水印/Logo"？（自身品牌不算）
- UGC 用户拍摄图片是否在画质上过度苛求？（UGC 只严查合规/完整性/相关性）
- 页面滚动导致的自然截断是否被误判为元素质量问题？（自然截断不算）
- 同一元素同时在多维度不达标时，是否只计了一个 🔴（不重复计数元素个数，但问题维度都记录）？
- 本指标是否误用了"达标"中间档？（本指标只有优秀/不达标两档，不设达标）

## 分支处理

| 场景 | 处理方式 |
|------|---------|
| 单张截图、单个 Tab | 直接分析，输出明细 + 总览 + 总结 |
| 多张截图、同一 Tab 不同屏 | 分屏分析后合并为一份完整报告，元素按出现顺序统一编号 |
| 多张截图、不同 Tab | 每个 Tab 独立分析，分别输出表格和评测结论 |
| 多张截图、不同搜索词 | 每个搜索词独立评测，最终汇总所有搜索词的评测结果 |
| 元素因页面滚动仅部分可见 | 仅分析可见部分，不将自然截断视为质量问题；若可见部分本身有质量问题，正常判定不达标 |
| 同一元素横跨两屏截图 | 以信息更完整的一屏为准，只分析一次 |
| 商卡展开了团购横滑区 | 每个团购商品图和团购商品标题各为独立元素，逐一检查 |
| 商卡未展开横滑区（仅文字行团购） | 团购文字标题为独立文字元素，逐一检查 |
| 商家自制宣传图含品牌 Logo/营销文案 | 属于正常商家运营行为，品牌 Logo 和营销文案不算"无关水印/Logo"，不影响画质判定 |
| 图片内容与搜索词弱相关但与商卡业态相关 | 若图片内容与商卡本身的服务/品类相关（如搜索"按摩"，商卡为康复机构，头图展示康复训练场景），判定为优秀；仅当图片与商卡自身业态也明显无关时才判定不达标 |
| 图筛文字使用了用户不常用但语义正确的表达 | 需具体判断：如果用户能自然理解且不产生困惑，判定优秀；如果使用了行业术语或内部分类名导致用户有理解成本，判定不达标 |
| 文字存在错别字但不影响核心语义 | 仍判定为不达标——准确性是底线要求，错别字无论是否影响理解都不达标 |
| 价格文字被部分截断 | 若价格数值不完整（如仅显示"¥3"无法判断是30还是300），判定为文字完整性不达标；若仅原价划线价被截断但现价完整，判定为优秀 |
| UGC 内容图片质量较低（用户拍摄，非专业图） | UGC 内容图片的画质标准可适当放宽（用户拍摄的照片清晰度、构图不做苛求），但合规性、完整性、相关性仍需严格检查 |
| 搜索词/场景无法识别 | 询问用户确认搜索词或页面场景 |
| 全部为优秀元素 | 输出总览表并在总结中注明"该搜索结果页供给呈现质量优秀，未发现低质量供给元素" |
| 用户要求与之前分析合并 | 回溯之前的分析结果，按多屏合并格式输出完整报告 |
| 截图中出现广告/营销 Banner | Banner 中的图片和文字同样作为独立元素检查，适用相同标准 |

## Gotchas

- **评估粒度是"单一元素"而非"组件"**：不要以商卡为单位笼统打分。同一商卡内，头图可能不达标但标题优秀，团购图A不达标但团购图B优秀——必须逐元素独立判定。这是本 Skill 与 `supply-completeness-scanner`（组件维度）的核心区别。
- **只有"优秀"和"不达标"两档，没有中间态**：供给质量是底线指标，图片加载失败、图文不符、错别字等问题没有"轻微"和"严重"之分，出现即不达标。不要因为"只有一点点问题"就给"达标"——本指标不设达标档。
- **"正常末尾省略"与"严重截断"的区分是关键判断点**：团购标题因展示空间限制以"..."结尾是正常的，只要核心信息（服务名称/价格/时长等）已在可见部分完整呈现，不判定为不达标。但如果标题被标签/角标等 UI 元素严重挤占，导致用户连店名或核心服务都看不清，那就是不达标。判断标准是"用户能否从可见部分获取关键决策信息"。
- **商家品牌元素不等于"无关水印"**：商家宣传图上的自身品牌 Logo（如"推匠堂 CHINESE MASSAGE"）和营销文案（如"匠人师傅精准手法"）是正常的品牌运营行为，不是画质问题。只有与该商家/商品无关的第三方水印、版权标记、其他平台 Logo 才算"无关水印/Logo"。
- **图片相关性判断要结合上下文**：不要孤立地看一张图片，要结合它所在的搜索词、商卡标题、团购标题来判断。比如一张泡池照片在"按摩"搜索结果中是相关的（洗浴按摩场景），但在"蛋糕"搜索结果中就是不相关的。
- **UGC 图片和商家专业图的标准差异**：UGC 用户拍摄的图片在清晰度、构图等方面不做专业级要求（这不是商家能控制的），但合规性（不得有违规内容）、完整性（必须正常加载）、相关性（必须与主题相关）仍严格检查。
- **团购横滑区的商品图是高频问题区**：从 badcase 经验看，团购横滑商品图是最容易出现"图文不符"（如人脸表情包代替商品图）和"加载失败"（空白/占位）的位置。扫描时需对该区域格外仔细。
- **"自然截断"不是质量问题**：页面滚动位置导致的元素部分不可见（如截图底部只露出半张商卡头图）、横滑列表边缘的自然裁切——这些都是交互设计的正常行为，不是元素自身的质量缺陷，不应判定为不达标。
- **图片合规性需特别审慎**：对于低俗擦边内容（如 badcase 中蛋糕上的低俗卡通形象），即使不构成严重违规，仍应标注为"合规性存疑"并在报告中特别说明，因为平台作为公开展示渠道对内容调性有更高要求。
- **一个元素可以同时在多个维度不达标**：如一张图片既加载失败（完整性不达标）又与搜索词无关（相关性不达标），两个问题维度都需记录。但该元素最终评级仍为一个 🔴 不达标，不重复计数元素个数。

## 示例

### 示例 1：图片相关性不达标

搜索词：鸭脖，外卖 Tab

商卡「滋味曹氏鸭脖（宝龙店）」的团购横滑区，商品图"微辣"和"中辣"展示的是人物面部表情包（影视剧截图），与鸭脖食品完全无关。

元素判定：团购商品图-微辣 🔴 不达标（图片-相关性：商品图为人脸表情包，与鸭脖食品完全无关）；团购商品图-中辣 🔴 不达标（图片-相关性：同上）。

### 示例 2：图片完整性不达标

搜索词：汉堡，到店 Tab

商卡「麦当劳（启阳路店）」的团购横滑区，"【品牌新人礼】麦辣鸡腿堡单"和"【翅堡喝足】堡堡双人餐6件"的商品图为空白/未加载，仅显示白色占位区域。

元素判定：团购商品图-品牌新人礼 🔴 不达标（图片-完整性：图片未加载，显示空白占位）；团购商品图-翅堡喝足 🔴 不达标（图片-完整性：同上）。

### 示例 3：图片相关性不达标 — 图文不符

搜索词：涮肉，到店 Tab

商卡「京门老爆三·铜锅涮肉爆肚」的团购横滑区，"铜锅涮肉双人餐"的商品图展示的是储值活动海报（"储值500送5"），而非涮肉菜品。"伏羊节上新"的商品图展示的是一只小羊羔的可爱照片，而非羊肉菜品。

元素判定：团购商品图-铜锅涮肉双人餐 🔴 不达标（图片-相关性：团购标题是菜品套餐，图片是储值活动海报，图文不符）；团购商品图-伏羊节上新 🔴 不达标（图片-相关性：标题为羊肉菜品，图片为活体动物照片，图文不符）。

### 示例 4：文字完整性不达标 — 被标签严重挤压

搜索词：蛋糕，到店 Tab

商卡「妙旺角·生日蛋糕」的店铺标题被前方多个标签（"热卖""直播中""臻选蛋糕"等）严重挤占，仅显示"妙旺角·生日蛋..."，用户无法获取完整的店铺定位信息。

元素判定：店铺标题"妙旺角·生日蛋..." 🔴 不达标（文字-完整性：标题被标签严重挤占导致核心信息截断，用户无法获取完整店铺名称）。

### 示例 5：图片合规性存疑

搜索词：蛋糕，到店 Tab

商卡「妙旺角·生日蛋糕」的第一个商品图"男生蛋糕8英寸"展示了一个蛋糕，蛋糕上画有裸露上身的卡通男性形象，配文"人美胸大 生日快乐大兄弟"，内容存在低俗倾向。

元素判定：团购商品图-男生蛋糕 🔴 不达标（图片-合规性：蛋糕图案含低俗卡通形象及文字，作为平台公开展示内容不够得体）。

### 示例 6：全部元素优秀

搜索词：咖啡，到店 Tab

商卡「瑞幸咖啡（恒基伟业大厦店）」：头图为品牌 Logo，清晰完整。团购横滑区展示4款饮品（拿铁、生椰丝绒拿铁、生椰杨枝甘露、丝绒拿铁），每张商品图均为清晰的饮品实物图，背景干净、色泽真实，与商品标题完全对应。标题"瑞幸咖啡(恒基伟业大厦店)"完整无截断。团购标题"拿铁""生椰丝绒拿铁"等完整可读。价格清晰。

元素判定：所有图片和文字元素均为 🟢 优秀。

### 示例 7：正常末尾省略 — 不判定为不达标

搜索词：按摩，全部 Tab

商卡「推匠堂.专业推拿调理馆.经络SPA Chin...」：店铺标题末尾被截断显示"Chin..."，但核心品牌名"推匠堂"和服务定位"专业推拿调理馆·经络SPA"已完整呈现，用户可获取关键决策信息。

元素判定：店铺标题 🟢 优秀（核心信息完整，末尾截断不影响用户决策）。
