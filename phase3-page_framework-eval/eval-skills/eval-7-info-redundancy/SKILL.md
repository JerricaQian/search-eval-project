## 三档解释与页面级证据展示契约

问题解释统一契约（必填）通用条款见 [[页面框架评测通用契约]]（`phase3-page_framework-eval/页面框架评测通用契约.md`），本 Skill 不重复列出。

### 简洁问题卡输出与示例（强制）

- 【技能专属】`observableFact` 必须写清重复功能或信息所在的页面区域。
- 【技能专属】示例输出：`品牌卡和业务图筛都提供“附近酒店”入口，但未提供不同筛选价值，评级为不达标。重复入口挤占首屏空间并增加选择成本。`

- 所有结论（包括优秀）必须保留一条整页 `assessmentRows`，写明核查事实、命中规则及评级解释。
- `details.evidenceMode`、优秀排除规则同 7 个 skill 逐字相同条款，详见 [[页面框架评测通用契约]]。

## Phase2 事实输入契约

- 页面区域、入口原文、模块功能描述、卡片归属、坐标及保守关系候选必须读取 `pageFacts.modules`、元素 `textFacts` 与 `relations`。
- Phase3 仍独立判断两个区域是否无增量价值；Phase2 不得预判功能/信息重复，`uncertain` 也不得被解释为重复。
- **候选为空不能反证无冗余：**`candidatePairs=[]` 不能单独支持优秀。优秀且 `redundancyCount=0` 时，`assessmentRows[0]` 必须保留 `scanCoverage.status="completed"`、覆盖全部 `pageRegions` 的 `scannedRegionIds`，以及逐区域两两核查的 `crossChecks`（数量至少为区域数的两两组合数）。
- **扫描覆盖必须来自当前页面事实：**不得汇总旧 `assessmentRows`、填入泛化页面区域或用固定结论脚本补造 `scanCoverage`。需要校正时，基于当前 `pageFacts.modules` 重新完成逐区域两两核查，再写入结论。

## 工具定位

本 Skill 用于评测搜索结果页/信息页截图中的**功能/信息无冗余**：在同一个页面内，是否存在同一类功能或信息在**不同区域**重复出现且无增量价值的情况。评测视角是**页面框架级**——关注的是页面不同区域（如品牌卡、视频大卡、业务图筛、快筛、商卡列表等）之间的功能/信息重叠，而非单张商卡内部的元素级语义重复。

适用场景：单张截图评测、同一搜索词多 Tab 截图评测、同一 Tab 多屏截图评测。

**与相邻评测项的边界：**

- **与组件维度 info-redundancy（组件/卡片内信息无冗余）的区别**：组件维度 Skill 关注单张商卡**内部**的语义重复（如标题与角标重复、标签间重复）；本 Skill 关注页面**不同区域之间**的功能/信息重复（如品牌卡的"附近酒店"入口与业务图筛的"酒店"入口功能重叠）。两者互不重叠，各自独立评测。
- **与 info-comparability（信息可比性）的区别**：info-comparability 关注同类信息在不同商卡间的表达方式是否一致；本 Skill 关注同一类功能/信息是否在页面不同区域重复出现。
- **与 supply-module-completeness（模块完整性）的区别**：supply-module-completeness 关注页面模块是否缺失或加载异常；本 Skill 关注页面模块之间是否存在功能/信息重叠。

## 核心概念

**功能/信息重复** = 同一类功能或信息在页面的**不同区域**重复出现，且后者没有提供增量价值（去掉其中一个不影响用户完成对应决策或操作）。

**功能/信息重复项数量** = 页面内指向同类内容或承担同类功能的重复入口/信息的数量。

**判断标准**：两个分属不同页面区域的元素（入口/信息），若它们指向同类内容或承担同类功能，且后者相对前者没有提供新的决策信息或操作路径，即计为 1 处功能/信息重复。

**关键词解释**：

- **不同区域**：页面中功能独立的模块/组件区域，如品牌卡/主点卡、视频大卡、业务图筛栏、快筛栏、商卡列表、"大家还在搜"推荐区等。同一区域内部的重复不属于本 Skill 范畴（属于组件维度 Skill）。
- **增量价值**：后者相对于前者是否提供了新的功能路径、新的决策信息或不同维度的内容。若有增量价值则不计为重复。

## 页面区域识别

评测前需先识别页面中的各功能区域。搜索结果页/信息页通常包含以下区域（不限于）：

| 区域 | 说明 | 典型位置 |
|------|------|----------|
| 搜索栏 | 显示搜索词、返回按钮 | 页面顶部 |
| 顶部横幅 | 攻略入口、活动标签等（如"迪士尼排队攻略""一日游抄作业"） | 搜索栏下方 |
| 品牌卡/主点卡 | 搜索词直接命中的品牌/POI 的聚合展示卡，通常含评分、标签、套餐、功能入口（如"景点门票""附近酒店""景酒套餐"） | Tab 栏下方、商卡列表上方 |
| 视频/品牌大卡 | 品牌宣传视频+信息+功能入口的大面积展示区 | 品牌卡下方 |
| 业务图筛栏 | 固定的业务品类导航入口（如"推荐""景点""酒店""美食""旅游产品""演出"），功能是品类切换 | 品牌卡或视频卡下方 |
| 快筛栏 | 排序/筛选条（如"综合排序""距离""全部分类"等） | 业务图筛下方 |
| 商卡列表 | 搜索结果的核心内容区，由多张商卡组成 | 页面主体区域 |
| "大家还在搜"推荐区 | 相关搜索词推荐 | 商卡列表中间或底部 |
| 底部模块 | 旅游产品、更多推荐等补充模块 | 页面底部 |

> **业务图筛 vs 意图澄清图筛**：业务图筛是固定的品类导航入口（推荐/景点/酒店/美食等），功能是品类切换；意图澄清图筛是展示搜索词相关的品种/规格/形态细分（如搜"榴莲"出现"金枕""黑刺"），功能是意图澄清。两者性质不同，在本 Skill 中都作为独立的页面区域参与跨区域重复判定。

## 判定规则

### 规则一：同一商家/POI 在页面多个区域重复展示

**定义**：同一个商家或 POI 以多种卡片形态（如品牌信息卡 + 视频品牌大卡、品牌卡 + 商卡列表中的同名商卡）在页面不同区域各自独立展示，且核心信息（商家名称、评分、功能入口等）高度重叠。

**判定**：若两个区域指向同一商家/POI，且都提供同类核心功能（如都含门票购买入口、都含商家详情入口），后者没有提供实质性增量价值，计为 **1 处功能重复**。

**增量价值的判定**：
- 视频内容、营销文案、活动入口（如"十岁庆典"）属于形式差异或运营内容，不构成实质性增量功能。核心功能（引导用户进入该商家详情页、购买门票/商品）仍与上方卡片重叠。
- 若后者提供了前者完全不具备的独立功能（如前者只有信息展示无购买入口，后者新增了购买入口），则不计为重复。

**示例**：
- 搜索"迪士尼"，页面上方有品牌信息卡（上海迪士尼度假区 + 景点门票入口），下方又有视频品牌大卡（同一个上海迪士尼度假区 + 超值门票入口）→ 两个区域指向同一商家、都提供门票购买入口，计为 1 处功能重复。

### 规则二：不同区域的功能入口指向同类功能

**定义**：页面中两个不同区域各自提供了一个功能入口，这两个入口承担同类功能（指向同类内容），且后者相对前者无增量价值。

**判定**：若两个入口功能同类、去掉其中一个不影响用户完成对应操作，计为 **1 处功能重复**。

**增量价值的判定**：
- 若两个入口虽然功能类似但指向的内容范围有实质差异（如一个是"全局品类切换"、一个是"当前 POI 周边推荐"），且用户点击后获得的结果集有显著不同，**仍可能构成重复**——关键判断点是：在当前搜索词的上下文中，两者呈现给用户的实际结果是否高度重叠。
- 例：搜索"故宫"时，品牌卡「附近酒店」和业务图筛「酒店」在该搜索词上下文中，用户实际获得的都是故宫周边的酒店结果，功能重叠 → 计为重复。

**示例**：
- 品牌卡中的「附近酒店」功能入口 vs 业务图筛栏中的「酒店」入口 → 在当前搜索词上下文中两者都引导用户查看该 POI 附近的酒店，承担同类功能，计为 1 处功能重复。
- 品牌卡中的「景点门票」入口 vs 视频大卡中的「超值门票」入口 → 都是门票购买功能入口，计为功能重复（通常会合并到规则一一起计数，不重复叠加）。

### 规则三：同一信息在页面不同区域重复展示且无增量

**定义**：同一条信息（如商家评分、地理位置、品牌名称等）在页面的不同区域各自展示，且后者没有提供任何新增信息维度。

**判定**：若同一信息在两个不同区域重复出现、去掉其中一个不影响用户获取该信息，计为 **1 处信息重复**。

**注意**：信息在自然从属关系中的重复不计入。例如品牌卡展示"上海迪士尼度假区 4.7分"，商卡列表中该商家的商卡也展示了"4.7分"——若商卡是独立的搜索结果卡片（而非品牌卡的附属），则两者属于不同功能定位（品牌直达 vs 搜索结果），不按信息重复计。

## 不计为重复的情况

以下情况不应判定为页面维度的功能/信息重复：

1. **单张商卡内部的语义重复**：如标题与角标重复、标签间重复等，属于组件维度 Skill（eval-8-info-redundancy）的评测范畴，不在本 Skill 中判定。

2. **不同商卡之间的相似商品/商家**：搜索结果列表中多张商卡展示相似的商品或同品类的不同商家，属于搜索结果的正常推荐逻辑，不算页面维度的功能/信息重复。

3. **搜索词与页面元素的文字匹配**：搜索栏中的搜索词与页面其他区域元素的文字相同（如搜"景点"，业务图筛也有"景点"），仅为文字层面的巧合重叠，不构成页面维度的功能/信息重复——搜索栏是输入区域，图筛是导航区域，两者功能角色不同。

4. **图筛与商卡标题/详情的相似文字**：图筛承担意图澄清或品类导航，商卡承担供给展示；图筛细节文字与卡片标题、规格或标签有相似表达，属于上下游决策信息，不构成跨区域重复。除非能证明两个区域提供完全相同的可操作入口或完全相同的信息，且删除任一不损失独立决策价值，否则不得计入。

5. **功能入口指向的内容范围有实质差异且结果集显著不同**：例如品牌卡「景酒套餐」（景点+酒店打包产品）vs 业务图筛「酒店」（纯酒店品类），两者功能定位和内容范围不同，不计为重复。

5. **业务图筛与快筛之间的功能差异**：业务图筛是品类切换（推荐/景点/酒店/美食等），快筛是排序与筛选（综合排序/距离/分类等），两者承担不同层级的功能，不构成功能重复。

6. **同一品牌/商家在品牌卡与商卡列表中分别出现，但功能定位不同**：品牌卡承担品牌直达/聚合展示功能，商卡列表中的同名商卡作为搜索结果之一出现，两者功能定位不同（品牌入口 vs 搜索结果），通常不计为重复——除非两者的信息和功能入口高度重叠且后者无增量。

## 评分标准

| 评级 | 条件 | 含义 |
|------|------|------|
| 🟢 优秀 | 功能/信息重复项数量 = 0 | 页面各区域功能/信息分工明确，无跨区域重复 |
| 🔴 不达标 | 功能/信息重复项数量 ≥ 1 | 存在功能/信息在不同区域重复出现且无增量价值 |

> **评级规则**：功能/信息重复项数量 = 0 → 🟢 优秀；≥ 1 → 🔴 不达标。本评级只有两档，无中间档。评级颗粒度为「搜索词 × 页面」，每个搜索词的每个页面（Tab）独立给出一个结论。

## 执行步骤

### Step 2：识别页面各功能区域

1. 逐张截图识别页面中的所有功能区域（参照"页面区域识别"表），记录每个区域的名称、位置和核心内容/功能。
2. 特别关注以下高频出现重复的区域组合：
   - 品牌卡/主点卡 与 视频品牌大卡
   - 品牌卡/主点卡的功能入口 与 业务图筛栏
   - 品牌卡/主点卡 与 商卡列表中的同名商卡
3. 区分业务图筛（固定品类导航）与意图澄清图筛（搜索词细分），两者在本 Skill 中均作为独立区域参与比对。

### Step 3：跨区域重复扫描

对 Step 2 中识别出的各区域，两两比对（重点关注高频组合），依次检查：

**3a. 同一商家/POI 是否在多个区域重复展示**
- 扫描页面中是否有两个或以上区域指向同一个商家/POI。
- 若存在，检查两个区域的核心信息和功能入口是否高度重叠。
- 高度重叠且后者无实质增量 → 记录为 1 处功能重复。

**3b. 不同区域的功能入口是否指向同类功能**
- 列出各区域中的功能入口（如品牌卡的"附近酒店""景点门票"，业务图筛的"酒店""景点"等）。
- 检查是否存在跨区域的两个入口承担同类功能。
- 在当前搜索词上下文中，两者引导用户获得的结果高度重叠 → 记录为 1 处功能重复。

**3c. 同一信息是否在不同区域重复展示且无增量**
- 检查是否有同一条信息（评分、商圈、品牌名等）在不同区域各自展示、去掉其中一个不影响用户判断。
- 排除自然从属关系中的重复（如品牌卡与其关联商卡的评分各自展示属于不同功能定位）。

**3d. 对每一处重复，记录：**
- 涉及的两个（或多个）区域名称
- 重复的具体功能/信息
- 为何判定为无增量价值（一句话理由）

### Step 4：汇总与评分

1. 统计本评测单元内的功能/信息重复项总数。
2. 数量 = 0 → 🟢 优秀；数量 ≥ 1 → 🔴 不达标。

### Step 5：输出结果

**单个搜索词 × 单个页面（Tab）输出格式：**

先列出页面区域识别结果（简要），再给出跨区域重复扫描的详细分析：

| 区域A | 区域B | 重复的功能/信息 | 增量价值判断 | 是否计为重复 |
|-------|-------|----------------|------------|:----------:|
| 品牌卡 | 视频大卡 | 同一商家展示+门票入口 | 视频形式差异不构成功能增量 | 是 |
| 品牌卡「附近酒店」 | 业务图筛「酒店」 | 酒店查找功能 | 当前搜索词下结果集高度重叠 | 是 |

末尾附评测结论：

> 🟢/🔴 **评级** — 搜索词「XXX」XX页面，功能/信息重复项数量 = N
>
> 一句话总结：列出具体重复点，或说明"页面各区域功能/信息分工明确，无跨区域重复"。

按「搜索词 × 页面」为最小颗粒度，逐个独立输出上述表格与结论，最后附一张汇总总表：

## Gotchas

- **本 Skill 只做跨区域比对，不做区域内部判定**：商卡内部标签间重复、标题与角标重复等属于组件维度 Skill（eval-8-info-redundancy）的范畴。本 Skill 的判定对象是页面中不同功能区域之间的重叠，务必在正确的粒度上操作。

- **搜索词与页面元素的文字匹配不是本 Skill 的判定范畴**：搜索栏是输入区域，其文字与页面其他区域元素（如业务图筛、商卡标题）的文字恰好相同，不构成"同一功能/信息在不同区域重复出现"。搜索栏与其他区域不做跨区域重复比对。

- **品牌卡功能入口 vs 业务图筛是高频重复点**：品牌卡/主点卡中常见的「附近酒店」「景点门票」「景酒套餐」等功能入口，若与业务图筛栏中的品类入口（如「酒店」「景点」）在当前搜索词上下文中指向高度重叠的结果集，应判定为功能重复。判断关键不是入口文字是否相同，而是**用户在当前搜索场景下通过两个入口实际获得的内容是否高度重叠**。

- **同一商家的多形态展示是另一高频重复点**：当一个商家同时以品牌信息卡和视频品牌大卡两种形态在页面出现时，虽然形式不同（一个是信息卡、一个有视频），但核心功能（展示该商家信息、引导用户进入详情页/购买）高度重叠，通常应计为 1 处功能重复。

- **增量价值要看功能实质而非形式差异**：视频内容、营销文案、活动入口等属于形式或运营层面的差异，不构成实质性功能增量。只有当后者提供了前者完全不具备的独立功能路径（如前者只有信息展示、后者新增了独立的交易流程入口），才能算作有增量价值。

- **"范围限定"不等于"增量价值"**：品牌卡的「附近酒店」虽然语义上限定为"该 POI 附近"，但在当前搜索词（如"故宫"）的上下文中，业务图筛的「酒店」呈现的结果同样是围绕该搜索词的，两者在实际用户体验中指向的内容高度重叠。不能仅因为入口文字多了"附近"两个字就豁免为"有增量价值"。

- **规则间去重，同一对区域不叠加**：若品牌卡与视频大卡已通过规则一判为 1 处"同一商家重复展示"，则两者之间的功能入口重叠（规则二）和信息重复（规则三）都包含在该 1 处之内，不额外叠加计数。但品牌卡与**其他区域**（如业务图筛）的功能重叠仍独立计 1 处。简言之：同一对区域之间的多种重复只算 1 处，不同对区域之间的重复各自独立计数。

- **每个评测单元独立判断**：不同搜索词、不同 Tab 之间的重复情况互不影响。不能因为"搜索词A没有重复"就放松对"搜索词B"的判断标准。
