## 评审对象与共同契约

遵循本维度[共享契约](../../contract.md)。一个由 Phase2 分开的标题、标签、价格或字段即是一个元素；不合并相邻元素取色。七色归并与渐变计数规则见 `references/7色标准.md`。

## Phase2 事实与测量门槛

- 先读取 `render`、`textFacts`、`visual`、`pageFacts` 的元素边界、语义角色、排除归属和已确认样式色值。只有 `visual.textColor/backgroundColor/borderColor` 中至少一个为非中性色的 UI 元素，才进入像素测量候选集。
- 黑、白、灰及低明度/低绝对色度的近黑、灰褐、灰蓝等感知中性色记为 `excluded:neutral_json_prefilter`，不运行裁剪或颜色脚本；若当前 Tab 没有任何非中性色候选，本项直接为优秀，并保留空候选集与全量排除记录。
- 必须仅对上述非中性色候选运行本 Skill 的 `scripts/count_element_colors.py`，在语义边界内取样；保存原始七色归并、面积占比、调试 mask、参数和产物路径。不得对全部中性色元素无差别跑脚本，也不得用整卡、旧裁剪或目测替代候选测量。
- 排除商家/下挂图片、营销图片、banner/腰封、金刚图标、元素外背景与相邻元素；标签本身不排除。中性色不进入颜色格，但保留在元素有效面积分母中；占元素有效面积小于 3% 的有彩抗锯齿/压缩杂色不计，渐变按跨越色格数计。
- **先定边界再取色：**标题、每个独立标签、价格、评分、按钮、提示条均是各自元素；相邻标签、卡片背景和照片中的像素不得合并到目标裁剪。
- **测量失败处理：**JSON 样式色值或边界不确定时先回退 Phase2；候选元素的背景 mask、当前版本或脚本产物任一项不可信时，阻断该元素的颜色结论并重取样；不能以“看起来颜色不多”给优秀。

## 判定标准

| 有彩色数（排除后） | 评级 |
|---:|---|
| ≤ 2 | 优秀 |
| 3 | 达标 |
| > 3 | 不达标 |

底色、文字色和元素内部 UI 图形均计入。按红、橙、黄、绿、青、蓝、紫七色归并；渐变跨越一个色类计一色、跨越多个色类按多个色计。每次只以当前截图重新取样；1.0/2.0 或其他批次的颜色、色数和结论均不可复用。

### 计色细则

1. 有彩底色、有彩文字和标签容器内的 UI 图形都计。统一门槛为 `S≥15、V≥20、RGB绝对色度≥20`；任一项未达到即作为感知中性色排除，这会过滤带轻微色偏的黑、白、灰，而不会把清晰的深棕、深红误删。
2. 同色相深浅合并到红、橙、黄、绿、青、蓝、紫之一；紫红归紫、黄绿归绿。渐变跨越的七色类别逐一计数。中性色不进入颜色种类，但仍保留在元素有效面积分母；色系占元素有效面积小于 3% 时作为抗锯齿/压缩杂色排除。
3. 圆角元素四角露出的页面底色必须以脚本背景排除参数去除；裁剪混入相邻标签时必须重裁，不得在错误 mask 上解释结果。

## 评分与聚合

- 每个可评元素依据排除后的色数评级：≤2 优秀，3 达标，>3 不达标。
- 按 frontmatter 对当前 Tab 取最差元素；最终 `weightedScore` 固定为优秀 `1`、达标 `0`、不达标 `-1`，而不是所有元素分数之和。
- `rawColorGrid/colorCount` 是评分证据，不能由 LLM 修改；文本解释只能说明脚本测得的色数和色系。

## 固定评审流程

1. **JSON 预筛：**从 Phase2 元素清单逐项确认可评 UI，再用已确认的前景/背景/描边色值区分非中性色候选与中性色排除项；照片、营销大图、金刚图标同样写入排除清单。
2. **候选裁剪与测量：**只对非中性色候选以语义边界裁剪；元素自身有彩底色必须保留，不能用四角取色把标签底色误删。运行脚本并保存中性/有彩像素数、色格、占比、mask 和调试图。
3. **核查：**先确认调试产物没有混入照片/相邻对象，再合并同色相深浅、处理渐变和 1% 阈值，最后套三档标准。
4. **输出：**每个问题行写目标原文、排除后的色数、中文色系和证据路径；再按最差元素写 Tab 评级与分数。

## 输出与反误判

- 候选总表固定字段：`coloredCandidateIds`、`neutralExcludedIds`、`prefilterEvidenceSource=phase2_json_visual_colors`。每个实际测量行固定字段：`elementId`、`componentId`、`phase2Boundary`、`sampleMask`、`rawColorGrid`、`colorCount`、`measurement.tool/artifactPath/parameters`、`rating`、`finding`。
- 不把黑白灰、极小噪点、照片和未确认图形计入；不因外部背景或相邻标签混色而扣分。
- 不能确认元素边界或脚本产物时阻断本项，不得硬写“优秀”或“不达标”。

## Gotchas

- 黄底黑字标签至少有一个黄色系；黑字不计不等于整枚标签排除。
- 标题与旁边的标签必须分开统计；一排独立标签也不能合成一个“大元素”。
- 采样产物模糊或边界漂移时，应回到当前截图重取样，不沿用历史颜色结论。
