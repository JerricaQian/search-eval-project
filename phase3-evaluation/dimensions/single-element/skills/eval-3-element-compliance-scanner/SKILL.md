## 评审对象与共同契约

遵循本维度[共享契约](../../contract.md)。逐元素比当前卡型与当前页面版本的规范，不用“标签通常在哪里”推定违规。判定前必读既有 `references/设计规范速查.md`；需要精确渐变、描边或阴影时读取 `references/商卡分区规范清单.xlsx` 的组件源样式字典。

## Phase2 事实门槛

- 元素边界、卡型、分区、可见文本、视觉规格桶和精确属性只读 `structure`、`render`、`textFacts`、`visual`；事实、版本或规范覆盖缺失时记录待确认，不判不达标。
- 图片、图片内文字、营销大图和金刚图标不在本项；头图角标、标题区履约标、权益/价格附近和下挂元素须按当前卡型规范确认，不能只凭位置判错。
- 字号直接按规范的 pt 阶梯比对；只从当前输入截图的已确认事实取样。
- **先读规范再判定：**先读 `references/设计规范速查.md`；需要精确渐变、描边或阴影时再读 `references/商卡分区规范清单.xlsx` 的组件源样式字典。不能凭记忆、其他卡型或旧版本规范作结论。
- **事实或规范缺口：**若当前卡型、分区、版本、源值或对应规范条目缺失，写“待确认/规范未覆盖”，不把它降为不达标，也不以历史设计补齐。

## 判定标准

对每一可评元素依次比：允许分区/出现条件、字号字重与字体、颜色语义、圆角、描边、阴影和标签容器样式。已确认出现无规范依据的装饰、或偏离当前规范即“不达标”，全部适用项符合即“优秀”。

P1–P10 规范灰区（同语义近似色、已知新店绿差异、允许的渐变角度小差等）一律“优秀”，注明 `规范内部待统一(Px)`；灰区不是元素违规。未知卡型、规范未覆盖或历史版本差异不是扣分依据。

### 比对顺序

1. 先确认卡型、页面版本和元素分区；“标签位于非标签区”本身不构成违规，必须有当前卡型对该位置的明确禁止。
2. 再按出现条件、字号字重/字体、颜色语义、底色圆角描边阴影、层级逐项比对。任一确认偏离或无依据的额外装饰为不达标，多个偏离要全部记录。
3. 精确色值只在规范要求精确值时比；标签底色优先比语义色系。近似色、P1–P10 灰区和轻微渐变角度差不扣分。

## 评分与聚合

- 每个可评元素为优秀或不达标；已确认偏离任一适用规范即不达标，灰区和待确认不进入不达标计数。
- 先完成元素行，再按 frontmatter 取当前 Tab 最差元素；最终 `weightedScore` 为优秀 `1` 或不达标 `-1`，不会因一元素多处偏离重复扣分。

## 固定评审流程

1. **准备：**读取当前规范，按 Phase2 建立“元素—卡型—分区—版本”表；排除图片、营销大图和金刚图标。
2. **取值：**截图先放大，读取当前元素已确认的字号、字重、颜色和容器事实；必要时记录渐变、描边、阴影等实际样式。
3. **比对：**逐项写实际值、规范期望和规范来源；分别标注明确偏离、P1–P10 灰区、规范未覆盖/待确认。
4. **汇总：**只用明确偏离得出元素与 Tab 评级；问题建议必须写目标元素、期望样式和验收结果。

## 输出与反误判

- 固定字段：`elementId`、`cardType`、`region`、`currentValue`、`expectedValue`、`ruleSource`、`rating`、`finding`、`observableFact`。
- `不达标` 必须同时有确认的当前分区/样式事实和对应规范期望，不能用其他卡型、旧版色值或位置惯例补齐证据。
- 不得将“元素放错分区”与“样式不符”混为一项；前者需有当前卡型明确禁令。

## Gotchas

- 字号必须使用规范的 pt 阶梯；不可从其他截图、历史版本或视觉密度反推数值。
- “优选新店”等已知规范灰区应写明 P 编号并判优秀，不能把规范待收敛当元素违规。
- 每个不达标必须同时给出实际值与期望值；只写“样式不规范”无法整改，也不能通过校验。
