# 组件/卡片评测

本目录的 8 项 Skill 以 Phase2 已确认的组件、卡片、区域或比较组为结论单位；元素只作为证据，不把页面问题降到卡内，也不把单元素问题重复记为组件问题。每项均按“评审对象与共同契约 → Phase2 事实/测量门槛 → 专属判定标准 → 评级与问题项 → 固定流程 → 输出模板 → Gotchas”执行。

## Skill 清单

| Skill | 只评什么 | 评级与 Tab 分数 |
|---|---|---|
| `eval-1` 供给呈现质量 | 商卡、图筛或筛选组件的适用功能区域和关键信息是否完整可见 | 优秀 `0` / 不达标 `-2`，取最差组件 |
| `eval-2` 视觉秩序统一对齐 | 同类组件的关键结构一致性与由左至右、由重到轻的阅读顺序 | 优秀 `1` / 达标 `0` / 不达标 `-1`，取最差比较组 |
| `eval-3` 色彩运用逻辑性 | 组件有效 UI 的七色有彩色系数量 | 优秀 `1` / 达标 `0` / 不达标 `-1`，取最差组件 |
| `eval-4` 静态元素复杂度 | 商卡所有区域与图筛内的异形/异色标签、独立 icon 样式数 | 优秀 `0` / 达标 `-1` / 不达标 `-2`，取最差组件 |
| `eval-5` 商卡视觉层级 | 完整结果卡可读信息的实际视觉层级数 | 优秀 `1` / 不达标 `-1`，取最差卡 |
| `eval-6` 信息分区合理性 | 直接读取 JSON 坐标，检查组件内相邻分区内容包围盒是否存在正向间隔 | 优秀 `1` / 不达标 `-1`，任一确认接触/重叠即不达标 |
| `eval-7` 信息真实无歧义 | 同一组件内图文、标签、规格、价格标签等是否直接冲突 | 优秀 `0` / 不达标 `-2`，取最差组件 |
| `eval-8` 信息无冗余 | 图筛、快筛、推荐区和商卡内是否存在无损重复 | 优秀 `1` / 不达标 `-1`，任一区域确认重复即不达标 |

## 阅读顺序

1. 依据任务选择上表中对应的一个或多个 Skill；组件、卡片、区域和比较组的评测单位以目标 Skill 为准。
2. 先读 `contract.md` 与当前截图的 Phase2 原子事实。
3. 再完整读取目标 `skills/eval-*/SKILL.md`，按其专属门槛、遍历、测量、阈值、评级和 Gotchas 执行。只有商卡视觉层级使用校准后的 `glyphHeightPx` 像素测量；组件色彩、复杂度、视觉秩序、信息分区、真实性与冗余均直接读取并全量遍历 Phase2 JSON。
