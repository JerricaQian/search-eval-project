# 静态元素复杂度

该评测统计商卡或图筛内异形、异色标签实例和独立 icon 的样式种类。按可理解的标签容器或语义组计数：同一组合优惠标签或同一标签下挂中的多个文本原子只算一个实例；不同独立标签即使文案或样式相同也分别计入。

标签可以位于组件任意区域，也不要求拥有独立容器。促销、权益、状态、动态提示或评价说明等彩色辅助文字属于文本标签。标签候选中仅排除履约标签和中性色标签；主标题、核心评分值和主价格本身不属于标签候选。

每个标签先完成身份判断和原子成组，再生成五段式 `styleKey` 留证。`styleKey` 不用于去重：多个独立实例的完整 `styleKey` 相同时仍分别计数；但同一容器或语义组内的多个原子只构成一个实例。若画面疑似存在未被 Phase2 原子覆盖的 UI 角标，必须先回退 Phase2 复核，不能直接评分。

AI 执行细则、阈值和输出门禁以同目录的 `SKILL.md` 为准。
