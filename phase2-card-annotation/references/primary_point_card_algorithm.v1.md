# 主点卡算法（v1）

主点卡是结果流前的独立页面组件，不是结果列表商卡。先分类：`非商主点卡 / 商场主点卡 / 景点主点卡 / 医院主点卡`。

- 共同结构：搜索框、Tab、主点消歧条（可选）、主点卡、主点后的业务图筛（可选）、快筛、结果列表。
- 商场主点卡：头图、标题、导航 icon、评分、评价条数、距离、品类、地址、文字下挂推荐（标签+文本）。
- 景点主点卡：头图、景点履约标签、标题、评分/评价条数/AOI/距离、榜单/券/属性标签、文字下挂服务项。
- 非商主点卡（如直播大卡）是异构主点：直播视频、直播状态/观看人数、商品横滑项，不得强行套商家字段。
- 医院主点卡按医疗资质/等级、科室/地址、预约服务等独立字段识别。所有卡型只在可见且局部 OCR 确认时填值。
