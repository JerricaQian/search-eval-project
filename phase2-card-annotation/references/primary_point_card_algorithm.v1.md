# 主点卡轻量识别算法（v2）

## 页面级主点扫描（2026-08-19 校准）

结果列表前出现的主点大卡必须作为 `primary_point_card` 页面组件单独输出，不占 `results_list` 的 `listPosition`，也不能因为下方已有商家结果卡而省略。下挂商品按列分别拥有主价与原价；同一行的多个价格不可复制到每个商品项或串为一段文本。

主点卡位于普通结果列表之前，是页面模块，不占结果卡 `listPosition`。它必须具备稳定独立边界、前置位置、实体标题，以及 POI 身份与领域详情/商家指标。

可见变体包括商场、景点、医院、地铁/大学等：商场记录标题、评分/评价、距离、品类、地址与推荐下挂；景点记录评分/评价、位置、榜单/券/属性和服务项；医院记录医疗资质/等级、科室/地址与预约服务。非商直播/运营大卡不满足主点最小契约时，按页面运营模块或异构单元保真，不套商家字段。

所有字段只来自当前截图 CV/OCR。主点黄金样本仅用于推理后回归，不得提供生产坐标或文本答案。
