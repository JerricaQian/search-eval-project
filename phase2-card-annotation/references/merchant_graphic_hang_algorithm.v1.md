# 商家图文下挂轻量识别算法（v2）

## 最小契约

必须同时确认稳定边界、商家图文下挂拓扑、左侧商家头图、商家标题和独立商品图片组。评分、履约、价格和列表位置是辅助证据。

## 边界

1. 左侧近方形商家头图建立卡头。
2. 下一张商家头图之前、右侧商品列中的实际商品图片组归入当前卡。
3. 单个最右侧悬浮图片不能单独证明下挂；至少一个下挂商品须从视口 70% 宽度之前开始并与商家主体相连。
4. 左侧竖版神券/代金券属于特殊下挂，不能替代商品图片组。
5. 业务图片筛选、运营卡和主点卡图片不得成为结果卡种子。

确认卡型后，才可打开头图区、标题区、商家信息区、标签区、下挂商品区、特殊下挂和服务下挂。每个下挂商品的图片、名称、价格和角标分别记录；页边截断元素只写可见部分。

## 评分与可见性门控（2026-08-19 校准）

- 卡内 OCR 观察到 `x.x分` 或“暂无评分”时，必须产出独立的“评分”元素；不得把它粘在月售、评价条数、人均或品类的“商家基础信息”里，也不得因为它不是卡型最小证据而丢弃。
- 商家信息行中的评价条数、人均、品类、商圈/距离按视觉实体拆分。评分后的数字不得吸附到评分，例如 `3.9分1` 必须回退到同一行有界 OCR，而不是发布为原文。
- `naturally_cropped` 只描述当前卡片本体是否被屏幕边界裁断，不得因为其下挂商品横向截断、下一屏开始或 OCR 未识别到字段而标记为裁断。卡头、标题和基础信息完整可见时，商家卡本体应为 `complete`。

最后一张商家卡自然触底时，可继承上一张已确认商家图文下挂卡型；只豁免被截图裁掉的必需字段。当前可见乱码、OCR 分歧和明确广告证据仍阻断整页。
