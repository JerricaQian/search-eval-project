# 商家卡片-文字下挂：CV + 局部 OCR 算法（v1）

## 卡片契约

结果卡仅位于 `pageStructure.components[].results_list.components[]`，卡型为 `商家卡片-文字下挂`。一张卡按可见区域输出：`头图区 / 标题区 / 商家信息区 / 标签区 / AI推荐理由区（可选）/ 文字下挂区`。

`文字下挂区` 不是图文下挂商品格：每个下挂服务必须作为独立 `items[]` 项，包含 `价格 / 价格折扣标签（可选）/ 下挂商品名 / 下挂商品销量（可选）`。不得将两行服务、价格与销量合并成一条 visibleText。

## 识别顺序

1. 轻量 CV 定位搜索框、Tab、图筛/业务图筛、快筛、优惠筛选、结果列表及卡片外框。
2. 使用头图位置定位右侧标题、商家信息、标签、AI 推荐理由和文字下挂区域；识别失败时只保留 `uncertain`，不可把图文下挂规则套用到文字下挂。
3. PaddleOCR 仅识别各字段裁剪，按字段坐标分组，不执行整页 PaddleOCR：履约标签、标题、评分/新店、评价条数、人均、品类、AOI、距离、标签、AI 推荐理由及每条下挂服务各自裁剪。
4. 下挂的价格、折扣、名称、销量必须分别匹配。价格区不得越界读入下一条服务或上方标签区。

## 元素规则

- 标题区：履约标签（到店/外卖/上门/景点）+ 商家标题；外卖存在配送时长时单列。
- 商家信息区：到店优先评分/新店、评价条数、人均价、品类、AOI、距离；到家优先评分/新店、销量、起送费、配送费、配送距离。
- 标签区：神券、榜单、高优保障/属性/服务、动态信任、商家亮点等最小标签逐项输出。
- AI推荐理由区：只在独立可见文案行存在时输出；不得将它并入标签或下挂商品名。
- 文本下挂区：`价格`、`价格折扣标签`、`下挂商品名`、`下挂商品销量` 都是同一 `itemIndex` 下的独立字段。

## 黄金样本

`golden-samples/merchant-text-hang/` 包含 11 组组件级样本（原图/标注后）和游乐场、空调清洗两张元素级标注。元素级标注优先级高于 OCR；每次规则改动需重建 `golden-sample-results/merchant-text-hang/` 的 11 个 JSON。

任何 `uncertain` 均表示本地视觉事实未确认，不能被 Phase3 解释成元素缺失、问题、不达标、优秀或人工复核结论。
