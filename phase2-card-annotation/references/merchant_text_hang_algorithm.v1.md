# 商家文字下挂轻量识别算法（v2）

## 密集指标行校验（2026-08-19 校准）

文字下挂商卡的评分、评价条数、人均、品类和距离常在同一视觉行，但仍是独立字段。检测到 `x.x分` 时必须建“评分”元素；`x.x分4.8万条`、`4.7分2` 等粘连结果必须阻断并对该行重读。距离只接受完整的 `x.xkm` 字段，带前缀的 `图6.0km` 不能发布。评分缺失或粘连不得以“商家基础信息”非空视为通过。

## 最小契约

必须同时确认稳定边界、商家文字下挂拓扑、左侧商家头图、标题、纯文字下挂、商家指标，以及服务语义或履约信息。缺评分/评价数/新店/人均等商家指标时不能仅凭布局硬套卡型。

## 边界与字段

1. 以左侧商家头图和商家主体信息为卡头。
2. 将下一商家头图前的服务/商品文字块吸附到当前卡。
3. 存在独立横向商品图片组时优先考虑图文下挂；商品价格行本身不能证明文字下挂。
4. 图筛、业务筛选和运营模块不能成为商家卡种子。

标题、评分/新店、评价数、人均、品类、位置、距离、标签、推荐理由，以及每条下挂服务的价格/折扣/名称/销量分别记录。页面语义只有在整行满足字段形态时才能覆盖卡片区域角色；长标题尾部出现“35分钟”等附带信息时，不能把整行改判为履约字段。

初次使用 Tesseract 双版面，不按 OCR 置信度发布或切换。字段文法、字符连贯性、双布局一致性或卡型语义任一失败，均写入整页门控；主入口只对对应卡内裁剪自动重识别一次并重新执行整页门控。不得让视觉模型补读或让纠错器改写原文。
