# 搜索结果卡片领域契约（v1）

## 判定顺序

1. 先识别结果页模块：搜索栏、Tab、可选提示条/图筛/文筛/业务图筛/主点卡/业务运营卡、排序筛选、可选优惠筛选，最后才是结果卡片列表。完整顺序见 `search_result_page_taxonomy.v1.json`。
2. 仅在结果卡片列表中判卡片类型：商品、商家图文下挂、商家文字下挂、酒店、演出/电影、度假/酒店套餐。
3. 已确认卡型后，只使用该卡型所定义的区域；再在该区域内枚举元素。
4. 主点卡是结果列表前的可选页面模块，不是结果卡型。仅结果列表中七种框架无充分证据时，才以明确广告标/推广素材归为广告卡；其他为异构卡。证据不足时保持 `uncertain`。

`uncertain` 既不是元素缺失，也不是问题、"不达标"或"优秀"的依据；不得因此创建人工复核任务。

## 七种常见卡片

|卡片类型|区域顺序|关键区分证据|
|---|---|---|
|商品卡片|头图、标题、副标题、价格、商家|商品主图 + 商品价格 + 商品标题，右侧商品信息为主|
|商家卡片-图文下挂|头图、标题、商家信息、标签、下挂商品/特殊下挂/服务下挂|商家主体信息后跟横向商品图片与价格|
|商家卡片-文字下挂|头图、标题、商家信息、标签、AI推荐理由、下挂区|商家主体信息后为无商品图的商品/服务/组合下挂|
|酒店卡片|头图、标题、评分与推荐理由、位置、标签、价格（双列另有基础信息）|酒店/民宿标识、酒店等级、`¥…起`、满房/预订等酒店信息|
|主点卡片|实体标题、实体信息、领域下挂|地铁/大学、商场、景点或医院等 POI 实体及专属下挂|
|演出/电影卡片|头图（演出）、标题、演出/商家信息、价格|演出日期/场馆或影院近期场次，以及固定价格区|
|度假/酒店套餐卡片|头图、标题、套餐概要、标签、价格|旅游/酒店标识、天数或住景享吃行套餐枚举、套餐价格|

完整、机器可读的区域和元素枚举见 `search_card_taxonomy.v1.json`；其内容以七份原始规范为准。

## 约束

- “直播中”是**元素候选**，在商品卡片归入商家区的营业状态；在两类商家下挂卡归入头图区的左上直播标。必须先确认卡型和坐标区域，不能用词本身跨卡型硬判。
- 同名元素在不同卡型可处于不同区域，例如价格、标签、状态、评分。
- 文档中的“至多一项/至多一行/优先级”是该区域的展示契约；它可协助卡型与元素判定，但在 OCR 或视觉证据不确定时不可反推缺失。
