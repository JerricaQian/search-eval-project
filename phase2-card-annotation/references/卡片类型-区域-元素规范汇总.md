# 搜索结果卡片领域契约（v2）

## 判定顺序

先识别页面模块和结果列表，再按 `card_recognition_contracts.v1.json` 判断卡型，最后仅打开 `search_card_taxonomy.v1.json` 为该卡型允许的分区和元素。禁止先套区域模板再反推卡型。

已知卡型未满足最小契约时，有明确广告证据才归广告卡，否则归异构卡。卡型不得输出 `unknown`；字段证据不确定则阻断整页，不得解释成缺失、问题或优秀。

## 卡型与分区

| 卡片类型 | 主要分区 | 必需区分证据 |
| --- | --- | --- |
| 商品卡片 | 头图、标题、副标题、价格、商家 | 单商品重复边界、主图、标题、价格 |
| 商家卡片_图文下挂 | 头图、标题、商家信息、标签、下挂商品、特殊/服务下挂 | 商家头图与独立商品图片组拓扑 |
| 商家卡片_文字下挂 | 头图、标题、商家信息、标签、下挂 | 商家指标、服务/履约语义、纯文字下挂 |
| 酒店卡片 | 头图、标题、评分/推荐、位置、标签、基础信息（双列）、价格 | 显式酒店/民宿、房型规格+设备或民宿房源身份；逐卡列表/网格边界和价格 |
| 演出电影卡片 | 标题、价格、演出信息/影院场次、可选海报 | 演出/影院身份、海报或场次和价格 |
| 度假酒店套餐卡片 | 头图、标题、套餐概要、标签、价格 | 套餐身份、概要和价格 |
| 主点卡片 | 实体标题、实体信息、领域下挂 | 结果列表前位置、POI 身份和领域详情 |
| 广告卡 | 媒体、主要、辅助、操作 | 稳定边界与明确广告标 |
| 异构卡 | 按实际媒体、主要、辅助、操作区域 | 无已知卡型通过且无广告证据 |

主点卡在页面结构中是列表前模块，不占普通结果 `listPosition`。

## 元素纪律

- 同名元素在不同卡型可以属于不同分区；必须结合卡型、坐标与文本形态。
- `直播中`、`神券`、价格数字等只能作为元素/字段候选，不能单独决定卡型。
- 每个独立标签、icon、角标、腰封和图片分别记录，不得按颜色相近合并。
- 当前阶段不做通用圆角容器检测；无像素证据的形状写 `unknown`。
- 页尾自然截断只豁免截图外不可见证据，不豁免已显示乱码和 OCR 分歧。
