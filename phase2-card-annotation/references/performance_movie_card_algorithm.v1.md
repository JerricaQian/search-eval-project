# 演出电影卡算法（v1）

演出、电影为两种结果卡，不得使用商卡字段。

- 演出卡：`头图区 / 标题区 / 演出信息区 / 价格区`。标题区依次拆履约标（演出）、城市、演出标题；演出信息区拆评分、演出日期、演出场馆；价格区只记录价格区间。
- 电影卡页面：`搜索框 / Tab / 电影主信息卡 / 日期筛选 / 结果列表`。电影主信息卡拆海报、横幅/轮播、电影名、上映日期/时长/类型/导演、演员、好评率、评分/评论数、热映/待映计数；每张电影结果卡拆影院标题、起价、地址、距离、近期场次。
- OCR 必须局部裁剪；长标题可自然换行但不得合并评分、日期、地址或价格。乱码/低置信度写 uncertain，不作为可见事实。
