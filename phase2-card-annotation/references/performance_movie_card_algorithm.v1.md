# 演出/电影卡轻量识别算法（v2）

演出和电影共享一个卡型契约，但使用不同边界变体：

- 演出：以竖版海报和演出身份文本建立重复卡边界；记录标题、城市、日期、场馆和价格区间。
- 电影：以影院标题和场次块建立重复卡边界；记录影院、地址、距离、近期场次和起价。

已知卡型至少需要稳定边界、海报/场次拓扑、标题、演出/影院身份、价格，以及海报媒体或排期证据。缺价格时归异构卡而不是按最高分类分数硬套。

OCR 只发布可确认的当前原文。长标题可以自然换行，但价格、评分、日期、地址和场次须按结构字段分开；不读取 OCR 置信度，不使用视觉模型补读。

## 场馆与场次字段（2026-08-19 校准）

演出卡的“场馆”是日期行与价格行之间的独立文本行，必须写入“演出场馆”；价格区间（`¥68-299` 等）只可写入“价格区间”，两者不得互相复用元素或坐标。完整演出卡若已识别日期和价格却缺场馆，需重读这条中间行。电影场次严格为 `H:MM` 或 `HH:MM`；`17:555` 属于多字 OCR，必须阻断并重读。
