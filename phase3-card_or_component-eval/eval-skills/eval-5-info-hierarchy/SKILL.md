## 三档解释与证据展示契约

问题解释统一契约（必填）通用条款见 [[组件卡片评测通用契约]]（`phase3-card_or_component-eval/组件卡片评测通用契约.md`），本 Skill 不重复列出。

### 简洁问题卡输出与示例（强制）

- 【技能专属】`observableFact` 必须写清组件内实际一级强调对象或实测层级数。
- 【技能专属】示例输出：`C1 的价格、促销券和保障标签均使用一级强调样式，评级为不达标。用户无法在首眼确定商品价格这一核心决策信息。`

- 每个 Tab 无论评级为优秀或不达标，都必须输出覆盖全部完整可评测商卡的 `assessmentRows`（技能专属覆盖模式：覆盖全部完整可评测商卡）。每行必须写出该组件的 `sourceElements`（真实 elementId、原文、区域、视觉事实）、从高到低的 `weightSequence`、`tierTrace`（每个档位的成员及每次拆档/同档归并依据）、`levelCount` 和评级解释；不得用“头图/标题/基础信息/价格”等区域泛称替代实际元素与依据。任何一张卡缺少这些可复核事实时，当前 Tab 不得输出优秀，必须请求 Phase2 复核。
- `details.evidenceMode`、优秀排除规则同 8 个 skill 逐字相同条款，详见 [[组件卡片评测通用契约]]。

通用条款（Phase2 清单原子性、完整阅读标准、`issues` 引用真实 ID）见 [[组件卡片评测通用契约]]（`phase3-card_or_component-eval/组件卡片评测通用契约.md`）。以下为本 Skill 专属内容：

## 工具定位

本 Skill 用于评测**搜索结果列表卡片**的视觉层级质量，即组件内信息元素是否通过可感知的视觉权重差异（字号、颜色对比）形成清晰的层次结构。AI 负责识别每个结果列表卡片内可区分的视觉权重档位数（视觉层级数），并按标准给出评级结论。最终按**搜索词 × 组件**颗粒度输出评测结论。

> **组件全域核查铁律：**层级统计范围是整张商卡的可见边界，头图区、标题区、基础信息区、标签/价格区与文字/图文下挂区中的可辨识权重块都必须纳入序列；Phase2 的标签区不是层级元素的唯一来源，不得漏掉图片角标、价格强调或下挂商品条等跨分区权重块。

**仅衡量结果列表卡片：** 本维度只评测搜索结果列表中的商卡/商品卡组件（即结果列表区域内的卡片），不衡量图筛、筛选/排序条、详情页信息卡、运营 Banner 等非结果列表组件。若截图中不存在结果列表卡片，记为"该屏无可评测组件"。

**与同系列 Skill 的边界：**

- 本 Skill 关注"组件内信息元素是否通过视觉权重差异形成清晰层次"（视觉层级问题）。
- `eval-1-supply-completeness` 关注"该有的元素是否缺失/不可视"（供给完整性问题）。
- `eval-7-info-authenticity` 关注"呈现的信息是否真实无歧义"（信息真实性问题）。
- 三者互不重叠：同一组件可能同时被多个 Skill 分别评测，互不影响。

## 核心概念

### 视觉层级数

**定义：** 组件内可区分的**视觉权重档位数**，即把组件内所有视觉权重块（含文字元素与图片块）按视觉权重从高到低排列后，能被肉眼区分出的独立档位数量。

**判定口径：**

1. **视觉权重块按从高到低排列**：先将组件内所有可辨识的视觉权重块按权重高低排序。权重块含两类：**文字元素**（标题、价格、评分、销量、人均、商圈、标签、下挂文字等）和**图片块**（头图/封面图、下挂商品条/菜品横滑区、配图文区等独立图片区域）。视觉权重由以下因素共同决定——文字块看字号、字重、颜色对比；图片块看面积占比、色块饱和度/对比度、位置。字号大/面积大/字重重/颜色对比强的块权重高。
2. **相邻权重块的档位划分**：逐一比较相邻两个权重块，满足以下**任一**条件即视为"不同档位"：
   - **文字块之间**：字号差 ≥ 2pt（以视觉可感知的明显大小差异为准）；或颜色对比度有明显跳变——相邻文字颜色从中性色（黑/灰/白系）跳到彩色/强调色（橙、红、蓝、绿等品牌强调色），或反向跳变。同属中性色系或同属彩色系的不同深浅，不构成跳变。
   - **图片块之间、或图片块与文字块之间**：视觉面积或色块对比有明显落差（如大面积头图 vs 紧凑文字行；宽幅下挂商品条 vs 小标签）即视为不同档位。若图片块与相邻块视觉面积/对比无显著落差（如小幅图标与同级小标签），归为同档。
3. **视觉差异不可感知 → 归为同一档位**：相邻文字块字号差 < 2pt 且颜色对比无跳变（如同为中性灰系、字号接近），或相邻图片块/图文块视觉面积与色块对比无显著落差，归为同一档位，不另计层级。
4. **档位是"权重档位"而非"块的数量"**：多个块可同属一个档位（如评分、销量、人均、距离等灰色辅助信息若字号字重颜色接近，同属"基础信息档"，合计 1 个层级）。重点是"能分出几档视觉权重"，不是"有几个块"。

**判断关键：** 层级数衡量的是"组件视觉呈现是否有层次、层次是否在合理区间内"，而非"元素越多越好"。层级过少（≤2）说明信息扁平、缺乏主次；层级过多（≥6）说明视觉规格碎片化、缺乏统一性。

### 颜色分类参考

判定颜色对比跳变时，按以下分类：

- **中性色**：黑、深灰、中灰、浅灰、白等无色相的色系。
- **彩色/强调色**：橙（美团品牌橙）、红、蓝、绿等有色相的强调色，常见于价格、折扣、活动标签、榜单等需突出的信息。

价格用橙色、标题用深灰 → 二者相邻时颜色从中性跳到彩色，构成档位跳变；评分与销量同为灰色且字号接近 → 同档位。

## 评估标准

对**每个结果列表卡片**独立评估：

| 评级 | 条件 | 含义 |
|------|------|------|
| 🟢 优秀 | 视觉层级数 ∈ [3, 5] | 组件视觉层次清晰，主次分明且规格统一性良好 |
| 🔴 不达标 | 视觉层级数 ≤ 2 或 ≥ 6 | 组件视觉层次过少（信息扁平、缺乏主次）或过多（规格碎片化、缺乏统一性） |

> **评级判定顺序：** 先按"视觉层级数判定口径"逐对比较相邻元素，累计得出组件的视觉层级数；再对照区间判定：层级数 ∈ [3, 5] → 🟢 优秀；层级数 ≤ 2 或 ≥ 6 → 🔴 不达标。本评级只有「优秀 / 不达标」两档，无中间档。

## 执行步骤

### Step 1：接收截图并确认评测范围

1. 用户提供页面截图（单张或多张）。使用图片读取工具加载所有截图。
2. 识别搜索词（顶部搜索栏文字）；若为非搜索场景（如列表页），识别页面所属场景名称代替搜索词。
3. 识别当前 Tab/频道（全部、外卖、团购等），若页面无 Tab 概念可省略。
4. 若为多屏截图，记录屏次，最终需合并为一份完整报告。

### Step 2：识别页面中的结果列表卡片

从截图顶部到底部，按视觉顺序识别**结果列表区域**内的卡片组件。本维度仅衡量结果列表卡片，包括：

- **商卡/商品卡**：搜索结果列表中的每一张商品/商家卡片，每张作为独立组件评估，这是最常见的评测对象。

排除非结果列表组件：图筛、筛选/排序条、详情页门店信息卡、运营 Banner、底部导航等不参与本维度评测。

为每个组件编号并记录名称（取标题关键词简称）。**任一结果列表卡片的可见边界触及截图底边、导致卡片纵向结构不完整时，整张卡不参与本指标的层级统计、`overview.total` 或评级聚合；不得仅按残留可见部分计算层级数，也不得因其层级不足判为不达标。**若一整屏截图中不存在完整可评测的结果列表卡片，记为"该屏无可评测组件"。

### Step 3：确定该组件的视觉权重块清单

在统计层级前，先列出组件内所有可辨识的视觉权重块（文字元素 + 图片块），避免遗漏。

- **文字元素**：标题、价格、评分、销量、人均、商圈/地址、商家头图旁文字、下挂区文字、各类标签（榜单/活动/保障/品质）、券信息等。
- **图片块**：头图/封面图、下挂商品条（菜品横滑区整体）、配图文区等独立图片区域。下挂商品条若图片+配文一体呈现，整体计为一个权重块，不把单张菜品图各自拆开；仅作纯装饰/分隔的细线、底纹不作为独立权重块。
- 若某块在该业态下不适用（如纯信息类组件无价格、无下挂商品条设计），不计入清单，不参与层级统计。

### Step 4：逐组件统计视觉层级数

对每个组件，按以下步骤统计视觉层级数：

1. **按视觉权重从高到低排列权重块**：依据文字块的字号/字重/颜色对比、图片块的面积/色块对比，将 Step 3 列出的权重块排出一个由高到低的视觉权重序列。权重最高的块（通常面积最大或字号最大/字重最重/颜色最突出，如头图或标题）排在最前。
2. **逐一比较相邻权重块，划分档位**：从序列顶端开始，依次比较相邻两个权重块：
   - 文字块之间：字号差 ≥ 2pt，或颜色对比度有明显跳变（中性色 ↔ 彩色/强调色）→ 属于**不同档位**，新增一个层级；字号差 < 2pt 且颜色对比无跳变 → **同一档位**，不新增。
   - 图片块之间、或图片块与文字块之间：视觉面积或色块对比有明显落差 → **不同档位**，新增一个层级；无明显落差 → **同一档位**，不新增。
3. **累计档位数 = 视觉层级数**：完成全序列比较后，累计得到的独立档位数即为该组件的视觉层级数。
4. 对每一组档位，记录：档位序号、归属元素 `elementId`、原文、区域、字号/字重/颜色/图片面积等 Phase2 事实，以及判定依据（字号差/颜色跳变/面积落差/同档归并）。不允许仅以“头图”“标题”“基础信息”这种区域名作为档位证据。

### Step 5：汇总与评级

1. 记录该组件的视觉层级数。
2. 按评估标准判定评级：层级数 ∈ [3, 5] → 🟢 优秀；层级数 ≤ 2 或 ≥ 6 → 🔴 不达标。

### Step 6：输出结果

**6a. 组件级评测明细表：**

| 搜索词 | Tab/场景 | 组件 | 视觉层级数 | 档位构成 | 评级 |
|--------|----------|------|:---------:|---------|:----:|
| 搜索词 | Tab名 | 组件名 | N | 档位1:权重块; 档位2:权重块; … | 🟢/🔴 |

**6b. 评级分布汇总（按搜索词 × Tab 维度）：**

| 搜索词 | Tab/场景 | 🟢 优秀 | 🔴 不达标 | 总组件数 |
|--------|----------|:------:|:--------:|:-------:|
| 搜索词 | Tab名 | N | N | N |

**6c. 层级数分布统计：**

跨组件统计各视觉层级数的出现次数，用于发现系统性问题：

| 视觉层级数 | 评级 | 出现次数 | 涉及组件 |
|:---------:|:----:|:-------:|---------|
| N | 🟢/🔴 | N | 组件名列表 |

若某一极端层级数（如 ≤2 或 ≥6）在多个组件中反复出现，应重点标注：层级 ≤2 通常指向信息扁平化、缺乏主次引导的设计缺陷；层级 ≥6 通常指向文字规格碎片化、缺乏统一性的设计缺陷。

**6d. 总结说明：**

在表格下方附一段文字总结，包含：不达标组件的具体问题和典型场景（如"某类商卡视觉层级数普遍为 2，标题与价格与辅助信息字号接近、缺乏主次"）、层级数分布反映出的系统性问题、以及建议设计优化的方向（层级过少 → 增加主次对比；层级过多 → 收敛文字规格、合并近似档位）。

## 分支处理

| 场景 | 处理方式 |
|------|---------|
| 单张截图、单个 Tab | 直接分析，输出明细表格 + 评级分布 + 总结 |
| 多张截图、同一 Tab 不同屏 | 分屏分析后合并为一份完整报告，组件按出现顺序统一编号 |
| 多张截图、不同 Tab | 每个 Tab 独立分析，分别输出表格和评测结论 |
| 多张截图、不同搜索词 | 每个搜索词独立评测，最终汇总所有搜索词的评级分布 |
| 组件底部被截断或卡片可见边界触及截图底边 | 该卡结构不完整，整卡排除：不统计层级数、不写 `assessmentRows`、不计入 `overview.total`，也不参与 Tab 聚合 |
| 组件内元素极少（仅标题+价格或更少） | 如实统计，通常层级数 ≤ 2，判 🔴 不达标（信息扁平、缺乏主次） |
| 组件含下挂菜品横滑区 | 下挂商品条整体（图片+配文）计为一个图片块权重块，纳入序列比较；不把单张菜品图各自拆开 |
| 同一行内多个并排字段（评分+月售+距离） | 各自作为独立元素纳入权重序列比较；若字号字重颜色接近，会被归为同一档位，不新增层级 |
| 标签/胶囊内文字 | 按实际字号字重颜色纳入序列比较，通常字号小、属独立档位 |
| 多个元素字号字重相同仅颜色不同 | 颜色从中性跳到彩色才算跳变；同为彩色系不同色相（如橙 vs 红）若字号字重相同，视觉差异不可感知，归同一档位 |
| 组件业态在整批截图中本就不含某块（如生活服务无价格） | 该块不计入权重块清单，不参与层级统计，说明中注明"该业态无此块" |
| 同一批次中同类组件层级数差异大 | 仍逐组件独立评级并如实记录，差异本身可指向设计执行不一致 |
| 搜索词/场景无法识别 | 询问用户确认搜索词或页面场景 |
| 用户要求与之前分析合并 | 回溯之前的分析结果，按多屏合并格式输出完整报告 |
| 页面中无结果列表卡片（纯图筛/纯导航） | 记为"该屏无可评测组件"，不输出评级 |
| 单张截图内结果列表卡片数量过多（如 10 张以上） | 仍逐一分析不做抽样，但可在明细表中用简写编号（商卡1、商卡2…）控制表格长度 |

## Gotchas

- **视觉层级数衡量的是"能分几档"，不是"有几个元素"**：一个档位可包含多个元素。评分、销量、人均三行辅助信息若字号字重颜色接近，同属一个"辅助信息档"，合计 1 个层级。把每个元素都算一个层级是最高发的误算。
- **档位划分依据是相邻比较，不是绝对规格**：判定靠"相邻两元素字号差是否 ≥ 2pt、颜色是否跳变"，必须先把元素按权重高低排成序列再逐一比相邻，不能凭"这个看起来大、那个看起来小"笼统数。
- **颜色跳变特指"中性色 ↔ 彩色/强调色"**：同为灰色系的不同深浅、同为彩色系的不同色相（橙 vs 红），若字号字重相同，视觉差异不可感知，不构成跳变。只有从中性色（黑灰白）跳到彩色/强调色（橙红蓝绿）才计为跳变。
- **字号差以 2pt 为门槛**：低于 2pt 的字号差异视为视觉不可感知，归同一档位。不要因 1pt 的细微差异就拆档。
- **层级不是越多越好，也不是越少越好**：[3, 5] 为优秀区间。≤2 是信息扁平、缺主次；≥6 是规格碎片化、缺统一性，二者均判不达标。
- **头图与下挂商品条要算作权重块**：头图/封面图、下挂商品条等图片块作为独立视觉权重块纳入档位统计，不是"只数文字"。下挂商品条若图文一体呈现，整体计为一个块，不拆单张菜品图。
- **组件颗粒度要逐一评估，不能整屏笼统打分**：同一页面中不同的**完整可见商卡**视觉层级可能差异很大，必须逐组件给出独立层级数与评级，才能定位具体问题组件；触底截断卡不具备完整层级证据，必须排除而非按残片判级。
- **"业态不适用"不能滥用为回避判断的借口**：只有当某块在该业态下确无此设计（且同批次截图中从未出现）时，才不计入权重块清单；不得因个别组件块少而简单归因于业态差异。

## 示例

### 示例 1：层级数 = 4 → 🟢 优秀

搜索词：啤酒，团购 Tab

商卡「Bacco Bar」权重块按视觉权重从高到低：店名（大字加粗，深灰）→ 价格（大字中等，橙色，与店名字号差 ≥ 2pt 且中性→彩色跳变，新档位）→ 评分+评论数+距离（中字常规，灰色，与价格字号差 ≥ 2pt，新档位）→ 活动标签（小字，胶囊内，与前述字号差 ≥ 2pt，新档位）。

档位构成：档位1=店名；档位2=价格；档位3=评分/评论/距离（同档归并）；档位4=活动标签。视觉层级数 = 4 → 🟢 优秀。

### 示例 2：层级数 = 2 → 🔴 不达标（信息扁平）

搜索词：滑雪场，生活服务场景

商卡「大川冰雪旅游度假区武当滑雪场运营中...」权重块按视觉权重从高到低：店名（中字加粗，深灰）→ 下方"暂无星级/暂无评价/距离1.9km"等信息（中字常规，灰色，与店名字号差 < 2pt、同为中性色，同档归并）。整个组件视觉规格接近，缺乏主次对比。

档位构成：档位1=店名；档位2=其余辅助信息（同档归并）。视觉层级数 = 2 → 🔴 不达标（层级 ≤2，信息扁平、缺乏主次引导）。

### 示例 3：层级数 = 6 → 🔴 不达标（规格碎片化）

搜索词：炒面，全部 Tab

商卡「左撇子十年炒饭」权重块按视觉权重从高到低：店名（大字加粗）→ 价格主体（大字，橙色）→ 划线价（中字，灰色）→ 评分（中字加粗，橙色）→ 月售（小字，灰色）→ "美团专送"标签（极小字，胶囊内）→ 起送/配送（小字，灰色）。相邻元素频繁出现字号差 ≥ 2pt 或中性↔彩色跳变，档位被拆得过细。

档位构成：6 个独立档位。视觉层级数 = 6 → 🔴 不达标（层级 ≥6，文字规格碎片化、缺乏统一性）。

需重点标注：该组件文字规格档位过多，建议收敛近似规格、合并辅助信息档，将层级数收敛到 [3, 5] 区间。

### 示例 4：同一档位归并多个元素 → 层级数 = 3 → 🟢 优秀

搜索词：啤酒，全部 Tab

商卡「优布劳精酿酒馆」权重块按视觉权重从高到低：店名（大字加粗，深灰）→ 评分4.7/733条评论/距离1.9km（同属中字常规、灰色，三者两两相邻字号差 < 2pt 且无颜色跳变，同档归并）→ 活动标签（小字，橙色，与辅助信息字号差 ≥ 2pt 且中性→彩色跳变，新档位）。

档位构成：档位1=店名；档位2=评分/评论/距离（同档归并3个元素）；档位3=活动标签。视觉层级数 = 3 → 🟢 优秀。

### 示例 5：业态不适用元素不计入 → 层级数 = 3 → 🟢 优秀

搜索词：酒店，酒店 Tab

商卡「某酒店」权重块按视觉权重从高到低：店名+类型（大字加粗）→ 评分+评论数（中字，与店名字号差 ≥ 2pt，新档位）→ 距离+地标+权益标签（小字，与前述字号差 ≥ 2pt，新档位）。价格字段在该业态下呈现在另一区域且规格与评分档接近，归并入评分档。

档位构成：3 个独立档位。视觉层级数 = 3 → 🟢 优秀。

### 示例 6：头图与底部商品条纳入计档 → 层级数 = 5 → 🟢 优秀

搜索词：搜索结果页

商卡权重块按视觉权重从高到低：头图（大面积封面图，权重最高）→ 标题/店名（大字加粗，深色，与头图面积落差明显，新档位）→ 基础信息（评分/评论/距离/人均等灰色辅助信息，同档归并，与标题字号差 ≥ 2pt，新档位）→ 推荐标签（高亮/彩色，与基础信息中性灰形成颜色跳变，新档位）→ 底部商品条（下挂商品展示区，与推荐标签面积落差明显，新档位）。

档位构成：档位1=头图；档位2=标题；档位3=基础信息（同档归并）；档位4=推荐标签；档位5=底部商品条。视觉层级数 = 5 → 🟢 优秀。信息有清晰落差，主次分明且规格未碎片化。

> 本例与示例 1-5 的区别：示例 1-5 侧重演示文字块之间的同档归并/颜色跳变逻辑（未展开头图等图片块）；本例演示**图片块（头图、底部商品条）作为独立权重块纳入档位统计**的口径。实际评测时，凡组件内存在头图、下挂商品条等独立图片块，均按本例口径计入档位。
