## 工具定位

本 Skill 用于评测搜索结果页截图中的信息真实性与歧义程度。AI 负责识别并计数页面中的**信息歧义**（组件内元素组合后产生信息冲突或矛盾），按组件颗粒度统计歧义数量并给出评级。最终按搜索词 × 组件颗粒度输出评测结论。

> **组件全域核查铁律：**歧义判断须覆盖整张商卡的全部可见分区，交叉核对头图及角标、标题/基础信息、标签/价格与文字或图文下挂内容；Phase2 分区仅为定位辅助，不能只在标签区或标题区内做局部比对，也不得把跨屏续接的下挂内容拆离其所属商卡。

## 核心概念

### 信息歧义

**定义：** 单一元素本身表意清晰，但与组件内其他元素组合后产生信息冲突或矛盾，导致用户对组件整体传达的信息产生多种解读。

**歧义类型：**

1. **图片与文字描述不一致**：商卡图片展示的内容与标题/副标题文字描述明显不符。
2. **主标题与副标题之间信息矛盾**：主标题传达的信息与副标题传达的信息相互冲突。
3. **标签之间信息矛盾**：同一组件内两个或多个标签传达了互相矛盾的含义。
4. **标题和下挂之间信息矛盾**：标题描述的内容与下挂商品/套餐展示的内容不一致。
5. **与搜索词冲突或矛盾**：组件主标题/图片与用户搜索词的核心意图明显不匹配，且组件内其他元素（如副标题）暗示与搜索词相关，导致用户对"这个结果是否匹配我的搜索"产生歧义。

**信息歧义数量** = 组件内歧义元素数量总和（每个独立的信息冲突点计 1 项）。

---

## 评估标准

对**每个组件**独立评估，按歧义数量评级：

| 评级 | 条件 | 含义 |
|------|------|------|
| 🟢 优秀 | 歧义数量 = 0 | 组件内信息自洽、无歧义 |
| 🔴 不达标 | 歧义数量 ≥ 1 | 存在信息歧义 |

> **评级判定顺序：** 歧义数量 = 0 → 🟢 优秀；歧义数量 ≥ 1 → 🔴 不达标。本评级只有「优秀 / 不达标」两档，无中间档。

## 执行步骤

### Step 1：接收截图并确认评测范围

1. 用户提供搜索结果页截图（单张或多张）。使用图片读取工具加载所有截图。
2. 识别搜索词（顶部搜索栏中的文字）。
3. 识别当前 Tab（全部/外卖/团购等）。
4. 若为多屏截图（如第一屏、第二屏、第三屏），记录屏次，最终需合并为一份完整报告。

### Step 2：识别页面中的组件

从截图顶部到底部，按视觉顺序识别以下组件类型：

**2a. 图筛组件**
- 图筛是搜索结果页顶部的图片+文字筛选入口区域。
- 整个图筛区域作为**一个组件**统一评估。
- 若该截图中无图筛（已滚动不可见或该 Tab 不展示），记为"无图筛组件"。

**2b. 筛选/排序条组件**
- 横向筛选标签栏（如综合排序、销量最高、距离最近等）。
- 作为**一个组件**统一评估。

**2c. 商卡组件**
- 商卡是搜索结果列表中的每一张商品/商家卡片。
- 每张商卡作为**独立组件**分别评估。
- 为每张商卡编号并记录商品/商家名称（取标题关键词简称）。
- 若商卡底部被截断，仅分析可见部分，在名称后注明"（部分截断）"。

### Step 3：逐组件扫描信息歧义

对每个组件，从上到下、从左到右逐元素扫描。不同组件类型的检查侧重点不同：

**图筛组件**：检查图筛内各筛选项的图片与文字是否一致（如筛选项图片展示A品类但文字标注B品类）。图筛项之间信息矛盾（如两个筛选项指向完全相同的含义但标注不同名称导致用户困惑）也计为歧义。

**筛选/排序条组件**：检查筛选项功能描述是否自相矛盾。通常筛选/排序条内容简单明确，歧义概率极低。

**商卡组件**：重点检查以下五类歧义：

**3a. 图片与文字描述是否一致**
- 商卡主图/缩略图展示的内容是否与标题/副标题文字描述匹配。
- 例：图片展示铁锅炖，标题写"猪脚饭" → 歧义。
- 例：图片展示猪脚饭，标题写"隆江猪脚饭" → 无歧义。

**3b. 主标题与副标题之间是否矛盾**
- 主标题和副标题传达的信息是否存在冲突。
- 例：主标题"清真牛肉面"，副标题"招牌猪肉水饺" → 歧义（清真与猪肉矛盾）。
- 例：主标题"隆江猪脚饭"，副标题"含绿豆汤" → 无歧义（补充信息）。

**3c. 标签之间是否矛盾**
- 同一组件内多个标签是否传达互相矛盾的信息。
- 例：同时出现"素食推荐"和"肉食榜第1名"标签 → 歧义。
- 例：同时出现"神抢手"和"满减"标签 → 无歧义（不同维度的促销信息）。

**3d. 标题和下挂之间是否矛盾**
- 标题描述的品类/商品与下挂展示的商品图片/名称是否一致。
- 例：标题"水果沙拉专营"，下挂全是炸鸡图片 → 歧义。
- 例：标题"隆江猪脚饭"，下挂展示猪脚饭套餐和其他菜品 → 无歧义。

**3e. 与搜索词是否冲突或矛盾**
- 组件的主标题和图片与用户搜索词的核心意图是否明显不匹配。
- **关键判断逻辑：** 仅当组件的主标题/图片与搜索词不匹配，**且**组件内存在其他元素（如副标题、标签）暗示与搜索词相关时，才构成歧义。如果整个组件与搜索词完全无关且也不声称相关，则属于**召回相关性问题**，不属于信息歧义范畴。
- 例：搜索"隆江猪脚饭外卖"，商卡主标题"东北一绝铁锅炖"，图片为铁锅炖菜品，但副标题写"含隆江猪脚饭" → 歧义（主标题/图片与搜索词不匹配，但副标题暗示相关，用户对"这是不是猪脚饭"产生多种解读）。
- 例：搜索"隆江猪脚饭外卖"，商卡标题"阿祥嫂隆江猪脚饭"，图片为猪脚饭 → 无歧义。

**不算歧义的情况：**

- **副标题对主标题的补充说明**：副标题提供主标题未涵盖的附加信息（如"含绿豆汤""送饮料"），不构成矛盾。
- **不同维度的促销/品质标签**：如「神抢手」+「满减」+「日现宰」，分别传达活动热度、优惠方式、品质特征，是不同维度的信息，不构成矛盾。
- **商卡图片展示多品类但主体匹配**：图片中除标题品类外还展示了配菜、饮品等附加品，只要主体菜品与标题一致，不算歧义。
- **店名中的品类词与商品名一致**：如店名"阿祥嫂隆江猪脚饭"与套餐名"猪脚饭套餐"，店名中的品类词是品牌标识，不构成矛盾。
- **搜索词与组件完全无关且不声称相关**：组件与搜索词不匹配但自身也未声称相关，属于召回相关性问题，不属于信息歧义。

### Step 4：汇总与评级

1. 对每个组件，汇总歧义数量。
2. 按评级标准判定：歧义数量 = 0 → 🟢 优秀；歧义数量 ≥ 1 → 🔴 不达标。

### Step 5：输出结果

**5a. 信息歧义评测表：**

| 搜索词 | Tab | 组件 | 歧义数量 | 歧义说明 | 评级 |
|--------|-----|------|:--------:|---------|:----:|
| 搜索词 | Tab名 | 组件名 | N | 具体歧义描述 | 🟢/🔴 |

> 评级规则：歧义=0 → 🟢 优秀；歧义≥1 → 🔴 不达标。

**5b. 评级分布汇总（按搜索词 × Tab 维度）：**

| 搜索词 | Tab | 🟢 优秀 | 🔴 不达标 | 总组件数 |
|--------|-----|:------:|:--------:|:-------:|
| 搜索词 | Tab名 | N | N | N |

**5c. 总结说明：**

在表格下方附一段文字总结，包含：歧义集中出现的组件和歧义类型、高频歧义反映出的系统性问题、以及建议优化方向。

## 分支处理

| 场景 | 处理方式 |
|------|---------|
| 单张截图、单个 Tab | 直接分析，输出明细表格 + 评级分布 + 总结 |
| 多张截图、同一 Tab 不同屏 | 分屏分析后合并为一份完整报告，商卡按出现顺序统一编号 |
| 多张截图、不同 Tab | 每个 Tab 独立分析，分别输出表格和评测结论 |
| 多张截图、不同搜索词 | 每个搜索词独立评测，最终汇总所有搜索词的评级分布 |
| 截图中无图筛区域 | 记为"无图筛组件"，不输出图筛行 |
| 截图中无商卡 | 记为"无商卡"，不输出商卡行 |
| 商卡底部被截断 | 仅分析可见部分，名称后注明"（部分截断）"，歧义只判断可见元素 |
| 图筛/快筛被滚动隐藏 | 不可见区域不纳入分析 |
| 搜索词无法识别 | 询问用户确认搜索词 |
| 同一商卡横跨两屏截图 | 以信息更完整的一屏为准，只分析一次 |
| 团购 Tab 出现与搜索词品类不同的商家 | 检查组件内是否存在元素暗示与搜索词相关（如副标题提及搜索词品类）；若有，按"与搜索词冲突"判断歧义；若完全无关联暗示，属于召回相关性问题，不计歧义 |
| 组件内同时存在多项歧义 | 每个独立的信息冲突点分别计 1 项，累加为该组件的歧义总数；只要 ≥1 即判 🔴 不达标 |
| 用户要求与之前分析合并 | 回溯之前的分析结果，按多屏合并格式输出完整报告 |
| 全部 Tab（第一屏） | 通常包含图筛、筛选/排序条和前几张商卡，所有区域均需分析 |
| 全部 Tab（第二屏及更深） | 图筛通常已滚动不可见，筛选/排序条可能吸顶可见；重点分析商卡 |
| 外卖 Tab | 与全部 Tab 类似，关注外卖商卡的图片/标题/下挂是否自洽 |
| 团购 Tab | 通常无图筛；商卡为团购套餐卡，重点关注套餐图片/标题与搜索词的匹配度 |
| 全部 Tab 混合多种业态商卡 | 按统一规则逐张分析，不区分业态，歧义判定标准一致 |

## Gotchas

- **歧义是组件内元素"组合后"的判断**：单一元素本身不构成歧义，必须是两个或以上元素组合后才产生信息冲突。不要因为某个标签"看起来奇怪"就直接计歧义，要找到与之矛盾的另一个元素。
- **召回相关性问题 ≠ 信息歧义**：如果一个组件与搜索词完全无关，且组件自身也不声称与搜索词相关，这是搜索召回的相关性问题，不属于本评测范围。只有当组件内部存在"声称相关"与"实际展示不相关"的矛盾时，才构成歧义。
- **图片与文字要看"核心内容"是否一致**：商卡图片可能展示多个菜品，只要主体内容与标题描述的品类匹配即可，不要因为图片中出现了标题未提到的附加菜品就判定歧义。
- **促销/活动标签通常不构成歧义**：「神抢手」「满减」「日现宰」等促销或品质标签是不同维度的信息，它们之间通常不会产生信息矛盾。
- **本评测只看信息歧义，不评信息虚假/功能误导**：信息虚假（需对比落地页真实情况）、功能误导（提示条内容准确性）需结合截图外信息核实，不属于本评测范围，AI 不再标注待人工介入项，仅按歧义数量给评级。
- **评级是两档、按歧义数量阈值判定**：歧义数量 = 0 → 🟢 优秀；歧义数量 ≥ 1 → 🔴 不达标。无中间档，不因歧义数量多少在优秀/不达标之间再分档。
- **歧义数量按独立冲突点计数**：同一组件内如果图片与标题不一致（1项）、且标签之间也矛盾（1项），则歧义数量 = 2，不是 1。每个独立的信息冲突点单独计数。
- **副标题"含XX"类描述需重点关注**：当商卡主标题和图片与搜索词不匹配，但副标题声称"含XX"（XX与搜索词相关），这是最典型的歧义场景，要特别注意。

## 示例

### 示例 1：全部组件无歧义 → 🟢 优秀

搜索词：隆江猪脚饭外卖，外卖 Tab

商卡1「阿祥嫂隆江猪脚饭」：图片为猪脚饭，标题为"隆江猪脚饭"，标签"神抢手""满减"，信息自洽。商卡2、商卡3 同理。图筛展示外卖商品缩略图，与搜索词匹配。筛选/排序条"综合排序""速度优先"内容明确。

结果：所有组件歧义数量 = 0 → 🟢 优秀

### 示例 2：单项歧义即不达标（歧义 = 1）→ 🔴 不达标

搜索词：隆江猪脚饭外卖，团购 Tab

商卡1「东北一绝来自家乡的铁锅炖【招牌推荐】」：主标题为"铁锅炖"，图片为铁锅炖菜品，与搜索词"隆江猪脚饭"不匹配；但副标题写"含隆江猪脚饭 5家门店通用"，暗示与搜索词相关。主标题/图片与副标题组合后，用户对"这是不是猪脚饭团购"产生歧义。歧义数 = 1（与搜索词冲突或矛盾）。

结果：歧义数量 = 1 → 🔴 不达标（单项歧义即触发，无需歧义数量≥2）

### 示例 3：多项歧义叠加（歧义 = 2）→ 🔴 不达标

搜索词：素食沙拉，全部 Tab

商卡1「XX餐厅」：图片展示烤肉拼盘（与"素食沙拉"搜索词不匹配），标题为"健康轻食套餐"（与图片矛盾），副标题"含素食沙拉选项"（暗示与搜索词相关）。歧义点：图片与标题不一致（1项）+ 图片/标题与搜索词冲突且副标题暗示相关（1项）= 歧义数 2。

结果：歧义数量 = 2 → 🔴 不达标

### 示例 4：图筛组件内部歧义 → 🔴 不达标

搜索词：精酿啤酒，全部 Tab

图筛区域某筛选项：图片展示的是果啤包装，文字标注却为"原浆啤酒"，图片与文字描述不一致，用户对该筛选项指向的品类产生歧义。歧义数 = 1。

结果：图筛组件歧义数量 = 1 → 🔴 不达标（图筛作为整体一个组件评估，组件内任一歧义即该组件不达标）
