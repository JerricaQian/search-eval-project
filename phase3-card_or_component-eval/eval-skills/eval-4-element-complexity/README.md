# 静态元素复杂度

该评测统计商卡或图筛内异形、异色标签和独立 icon 的样式种类。它关注的是静态 UI 样式复杂度，不是标签实例总数。

标签可以位于组件任意区域，也不要求拥有独立容器。促销、权益、状态、动态提示或评价说明等彩色辅助文字属于文本标签；主标题、核心评分值和主价格不属于标签。

每个标签先独立完成身份判断，再生成五段式 `styleKey`。多个实例的完整 `styleKey` 相同时只计一种样式。若画面疑似存在未被 Phase2 原子覆盖的 UI 角标，必须先回退 Phase2 复核，不能直接评分。

AI 执行细则、阈值和输出门禁以同目录的 `SKILL.md` 为准。
