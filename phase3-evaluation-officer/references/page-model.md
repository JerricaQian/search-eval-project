# 美团搜索结果页页面模型

## 页面目标与判断原则

搜索结果页服务用户高效获取并比较匹配结果，不是资源位集合。评测时使用五条总原则：用户价值优先；新增表达必须有增量价值；同一区域只突出一个决策重点；决策关键信息必须真实；操作与结果应稳定可预期。

## 模块拓扑

页面通常按以下顺序组织：

```text
搜索栏 → 心智 Tab → 需求澄清/主卡区 → 排序筛选 → 结果列表
```

固定骨架是搜索栏、Tab、排序筛选与结果列表。提示条、图筛、业务图筛、主点卡、业务运营卡、业务浮窗、优惠筛选，以及酒店/电影等意图专属面板均为条件模块。是否适用只认当前 Phase2 已确认的页面类型、容器或占位；其他词、其他 Tab 曾出现过的模块不能作为本页缺失基线。

## 模块角色

- 搜索栏：需求输入与返回/功能入口。
- Tab：结果心智切换；Tab 气泡只能是有增量价值的轻量引导，不能遮挡搜索框或首屏首条结果。
- 需求澄清：提示条、图筛、业务图筛用于消歧或细化意图，不是重复曝光搜索词的容器。
- 主卡区：主点卡/业务运营卡在结果头部承接 POI 或特定意图，不等同普通列表卡。
- 排序筛选：位置、排序、筛选和优惠条件；子项不是独立页面功能区。
- 结果列表：连续、可比较的自然结果卡；列表内中插/广告/异构卡只有占据列表位时才影响浏览动线。

## 三层对象边界

- 元素：最小独立文字、标签、图标、按钮、价格或评分；只评自身可见表达与样式。
- 组件/卡片：同一卡或同一筛选组件内的区域、层级和字段关系；跨字段冲突与冗余在此层处理。
- 页面：模块加载、区域对齐、首屏功能区、列表节奏、跨卡可比性和跨区域重复；不得重复记录卡内问题。

## 页面判断协议

先确认页面类型与已出现模块，再判模块内卡片。自然触底、跨屏续接或未完整显示的卡，只评当前可以确认的范围。列表外广告横幅不占列表位；不同卡型、不同业态、不同表达目的的内容不能强行横向比较。
