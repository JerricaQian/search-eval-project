# 美团搜索结果页卡型分类

卡型 `id` 与对外展示名称以仓库根目录的
[`card-type-registry.v1.json`](../../card-type-registry.v1.json) 为唯一来源。本文解释评测官如何理解卡型、区域和变体，不能另行改写名称映射。

## 正式卡型

| 卡型 | 典型区域 | 变体与判读重点 |
|---|---|---|
| 商品卡片 | 头图、标题、可选副标题、价格、商家 | 履约标签与商品标题、价格口径、规格/促销/商家信息是不同角色；不得把价格前缀或单位说明误并为同一字段。 |
| 商家卡片-文字下挂 | 头图、标题、商家信息、标签、可选 AI 推荐理由、文字下挂 | 下挂是商家主信息之后的补充内容；不以普通商品卡的价格/规格模板要求它。 |
| 商家卡片-图文下挂 | 头图、标题、商家信息、标签、商品/套餐/服务图文下挂 | 主商家与下挂商品是不同实体层；下挂可为商品、组合、特殊或服务形态。 |
| 商家卡片-无下挂 | 头图、标题、商家信息、标签/权益 | 属于商家卡片族的正式变体；没有文字或图文下挂不等于异构卡，也不能按商品卡模板要求价格/规格。 |
| 主点卡片 | 实体标题、实体信息、领域下挂 | 位于结果头部；分非商主点、商场、景点、医院，领域下挂分别可承载路线、商家集合、门票/酒店或医疗服务。 |
| 酒店卡片 | 头图、标题、评分与推荐理由、位置、标签、价格 | 标准酒店/民宿/双列房型变体不同；酒店/民宿履约标、酒店等级、动态房价与预订信息均有独立语义。 |
| 度假/酒店套餐卡片 | 头图、标题、套餐概要、标签、价格 | 自由行、跟团游、酒店套餐三种变体；套餐概要中自由行优先住→景→享→吃→行，跟团游强调团服务/保障与住行服务。 |
| 演出/电影卡片 | 标题、演出信息或影院信息、价格 | 演出含海报、城市、日期、场馆和区间价；电影含影院、地址、场次、距离和起价。 |

## 兜底卡型

- 广告卡：须有明确广告/推广文字或广告素材，且未满足七类正式卡型的充分证据。
- 异构卡：结果流中的稳定独立单元，不满足已知卡型且无广告证据。未知不是广告；分类失败也不是体验不达标。

## 通用槽位关系

`头图`、`标题`、`基础信息`、`标签/权益`、`价格`、`下挂`是区域，不是可互相替换的字段。履约、价格口径、销量、距离、评分、时间、规格和业务标签各有独立服务对象；评测冗余或矛盾时，先确认它们是否表达同一事实、是否能无损删除、是否存在单位或口径冲突。

不同业态不共用同一必备字段：外卖/即时零售不强套到餐人均或商圈；酒店动态房价入口不因未给固定金额判缺失；主点卡也不按普通商家卡的下挂模板判定。
