# 黄金事实契约

仓库 `phase2-card-annotation/golden-atomic-2.0/` 的 34 份 v3 黄金清单，提供了 135 张卡、658 个区域与 1975 个元素的结构范例。它们用于 Phase2 卡型、区域、槽位与坐标事实的回归，不是可复制到当前截图的答案。

## 原子事实图

```text
page.moduleIds
  → modulesById（模块角色、边界）
  → cardsById（卡型、变体、可见性、区域集合）
  → regionsById（区域名、边界、slots）
  → elementsById（文字/标签/媒体、边界、视觉事实）
```

评测官必须按此图确定：页面模块顺序、卡边界、卡型与变体、区域角色、标题/履约/价格/下挂等槽位关系。`elementId` 是追溯定位，不是用户报告文案。

## 当前图优先与阻断

- 当前截图只有在 Phase2 清单通过门禁后才能进入评分；黄金文件、样本文件名、历史坐标和历史文字不能补写当前事实。
- 已知卡型证据不足时，必须根据保守分类策略处理并回退 Phase2；不得以 `unknown`、猜测卡型或缺失 OCR 直接得出体验结论。
- Phase2 提供基础事实；Phase3 自己生成比较组、颜色统计、关系候选、冗余判定和评分，不能要求 Phase2 写入评测结论。
